Konfigurasi Wi-Fi & Access Point

Mempelajari fungsi access point, pengaturan SSID, password Wi-Fi, mode wireless, keamanan jaringan, dan koneksi client.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

  • Menjelaskan fungsi access point.
  • Memahami mode kerja access point.
  • Mengatur SSID dan password Wi-Fi.
  • Memahami keamanan jaringan wireless.
  • Menghubungkan client ke jaringan Wi-Fi.
01 — PERANGKAT

Apa Itu Access Point?

Access Point (AP) adalah perangkat jaringan yang menyediakan akses wireless agar perangkat seperti laptop dan smartphone dapat terhubung ke jaringan lokal.

Access point biasanya terhubung ke switch atau router melalui kabel Ethernet, kemudian menyebarkan jaringan menggunakan gelombang radio.

Contoh: Access point di sekolah digunakan untuk menyediakan koneksi Wi-Fi bagi siswa dan guru.
02 — FUNGSI

Fungsi Access Point

Menyediakan Wi-Fi

Menghubungkan perangkat tanpa kabel ke jaringan lokal.

Memperluas Jangkauan

Membantu menyediakan akses wireless di area yang lebih luas.

Menghubungkan Client

Melayani koneksi laptop, smartphone, dan perangkat wireless lainnya.

Mengelola Akses

Mendukung pengaturan nama jaringan dan keamanan koneksi.

03 — MODE KERJA

Mode Wireless

Access Point Mode

Perangkat bekerja sebagai pemancar jaringan Wi-Fi untuk menghubungkan client ke jaringan kabel.

Repeater Mode

Perangkat menerima jaringan wireless dan meneruskannya kembali untuk membantu memperluas jangkauan.

Bridge Mode

Digunakan untuk menghubungkan dua segmen jaringan melalui koneksi wireless, sesuai dukungan perangkat.

Client Mode

Perangkat bertindak sebagai client wireless yang terhubung ke access point lain.

04 — KONFIGURASI

Pengaturan Dasar Wi-Fi

Pengaturan dapat berbeda pada setiap merek access point. Secara umum, konfigurasi dilakukan melalui halaman administrasi perangkat.

  1. Hubungkan komputer ke access point menggunakan kabel jaringan atau koneksi yang tersedia.
  2. Buka browser dan akses alamat pengelolaan perangkat sesuai buku panduan.
  3. Masuk menggunakan akun administrator perangkat.
  4. Cari menu Wireless atau Wi-Fi Settings.
  5. Masukkan nama jaringan pada kolom SSID.
  6. Pilih pita frekuensi dan channel sesuai kebutuhan.
  7. Atur keamanan jaringan, misalnya WPA2-AES atau WPA3 jika didukung.
  8. Buat password Wi-Fi yang kuat.
  9. Simpan konfigurasi dan sambungkan client untuk pengujian.
Gunakan password administrator yang berbeda dari password Wi-Fi. Ganti kredensial bawaan jika masih digunakan.
05 — KEAMANAN

Keamanan Wi-Fi

  • Gunakan WPA2-AES atau WPA3 jika perangkat mendukung.
  • Gunakan password panjang dan tidak mudah ditebak.
  • Perbarui firmware perangkat secara berkala.
  • Nonaktifkan fitur yang tidak diperlukan.
  • Batasi akses administrasi hanya untuk pihak yang berwenang.
  • Gunakan jaringan tamu jika tersedia untuk pengunjung.
06 — PENGUJIAN

Menghubungkan Client

  1. Aktifkan Wi-Fi pada laptop atau smartphone.
  2. Pilih SSID yang sudah dibuat.
  3. Masukkan password jaringan.
  4. Tunggu hingga perangkat terhubung.
  5. Periksa apakah perangkat memperoleh alamat IP.
  6. Coba akses gateway atau layanan jaringan yang diizinkan.
Catatan troubleshooting: Jika client tidak dapat terhubung, periksa password, jangkauan sinyal, kapasitas client, pengaturan keamanan, dan layanan DHCP.
