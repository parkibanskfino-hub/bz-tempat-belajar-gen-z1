MATERI 01 • HARDWARE
🖥️

Pengenalan Hardware

Mengenal perangkat keras komputer, fungsi setiap komponen, serta cara kerja dasar sebuah komputer.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

  • Menjelaskan pengertian hardware.
  • Menyebutkan komponen utama komputer.
  • Menjelaskan fungsi setiap komponen.
  • Membedakan perangkat input dan output.
01 — DASAR

Apa Itu Hardware?

Hardware atau perangkat keras adalah bagian komputer yang mempunyai bentuk fisik sehingga dapat dilihat dan disentuh.

Hardware bekerja bersama software untuk menjalankan berbagai tugas pada komputer.

Contoh hardware:
🖥️ Monitor ⌨️ Keyboard 🖱️ Mouse 🧠 Processor 🧩 RAM 💾 SSD
02 — KOMPONEN

Komponen Utama Komputer

Setiap komponen komputer mempunyai fungsi yang berbeda. Berikut beberapa komponen penting yang perlu kamu kenali.

🧠

Processor / CPU

CPU merupakan komponen yang menjalankan dan memproses instruksi dari program komputer.

  • Memproses instruksi
  • Melakukan perhitungan
  • Mengatur proses komputer
🔌

Motherboard

Motherboard merupakan papan utama tempat berbagai komponen komputer terhubung.

  • Menghubungkan komponen
  • Menyediakan jalur komunikasi
  • Menghubungkan perangkat lain
🧩

RAM

RAM merupakan memori sementara yang digunakan saat komputer menjalankan program.

  • Menyimpan data sementara
  • Membantu multitasking
  • Mendukung kinerja aplikasi
💾

Storage

Storage digunakan untuk menyimpan sistem operasi, aplikasi, dokumen, foto, video, dan data lainnya.

  • HDD
  • SSD SATA
  • SSD NVMe
🎮

GPU / Graphics Card

GPU digunakan untuk mengolah tampilan grafis yang ditampilkan pada monitor.

  • Game
  • Editing video
  • Desain grafis
  • Rendering
⚡

Power Supply / PSU

PSU menyediakan dan mendistribusikan daya listrik yang dibutuhkan oleh komponen komputer.

  • Menyuplai listrik
  • Mengatur distribusi daya
  • Memberikan daya ke komponen
03 — PERANGKAT

Input dan Output

Perangkat input digunakan untuk memasukkan data, sedangkan perangkat output digunakan untuk menampilkan hasil pemrosesan.

⌨️ Perangkat Input

Digunakan untuk memasukkan data atau perintah ke komputer.

  • Keyboard
  • Mouse
  • Microphone
  • Scanner
  • Webcam

🖥️ Perangkat Output

Digunakan untuk menampilkan hasil pemrosesan komputer.

  • Monitor
  • Printer
  • Speaker
  • Projector
04 — CARA KERJA

Bagaimana Komputer Bekerja?

Secara sederhana, komputer dapat dipahami melalui tiga tahapan utama: input, process, dan output.

1

Input

Pengguna memasukkan data atau perintah menggunakan keyboard, mouse, dan perangkat input lainnya.

→
2

Process

CPU dan komponen lainnya memproses data sesuai instruksi yang diberikan.

→
3

Output

Hasil pemrosesan ditampilkan melalui monitor, speaker, printer, atau perangkat lainnya.

💡

Tips Mengingat Komponen

Anggap komputer seperti sebuah tim. CPU bertugas memproses, RAM menjadi ruang kerja sementara, storage menyimpan data, motherboard menghubungkan berbagai komponen, sedangkan PSU menyediakan daya.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ Hardware adalah perangkat komputer yang memiliki bentuk fisik.
✓ CPU bertugas memproses instruksi.
✓ RAM digunakan sebagai memori sementara.
✓ Storage digunakan untuk menyimpan data.
✓ Motherboard menghubungkan berbagai komponen komputer.
✓ PSU menyediakan daya untuk komputer.
