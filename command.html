Command Line Linux

Pelajari perintah terminal Linux untuk mengelola sistem dengan lebih cepat dan efisien.

💻 Belajar Linux dari Terminal

Command Line Interface (CLI) memungkinkan pengguna berinteraksi dengan sistem operasi melalui perintah teks. Materi ini membantu kamu memahami perintah dasar yang sering digunakan pada Debian dan Ubuntu.

📘 1. Pengertian Command Line Linux

Command Line Interface (CLI) adalah antarmuka yang digunakan untuk berkomunikasi dengan komputer melalui perintah berbentuk teks. Di Linux, perintah biasanya dimasukkan melalui aplikasi terminal.

Berbeda dengan Graphical User Interface (GUI) yang menggunakan jendela, ikon, dan tombol, CLI mengandalkan perintah yang diketik pengguna.

Contoh: Perintah pwd digunakan untuk mengetahui lokasi direktori yang sedang aktif di terminal.

🎯 2. Fungsi Command Line

📁 Mengelola File

Membuat, menyalin, memindahkan, dan menghapus file atau direktori.

👤 Mengelola User

Membuat pengguna dan mengatur hak akses melalui perintah yang sesuai.

⚙️ Administrasi Sistem

Memeriksa informasi sistem, proses, layanan, dan penggunaan sumber daya.

🌐 Mengelola Jaringan

Memeriksa alamat IP, konektivitas, dan konfigurasi jaringan.

⌨️ 3. Cara Membuka Terminal Linux

Terminal dapat dibuka melalui beberapa cara, tergantung lingkungan desktop.

  • Cari aplikasi bernama Terminal pada menu aplikasi.
  • Pada banyak lingkungan desktop, tekan Ctrl + Alt + T.
  • Pada sistem Linux tanpa desktop, gunakan konsol teks jika tersedia.

Contoh tampilan terminal

siswa@debian:~$

Keterangan:

  • siswa adalah nama pengguna.
  • debian adalah nama komputer atau hostname.
  • ~ biasanya menunjukkan direktori home pengguna.
  • $ umumnya menandakan shell berjalan sebagai pengguna biasa.
Simbol prompt dapat berbeda. Shell yang berjalan dengan hak root biasanya menampilkan #, tetapi simbol tersebut bukan satu-satunya cara untuk memastikan tingkat hak akses.

📂 4. Perintah Dasar Navigasi Direktori

A. pwd — Melihat lokasi direktori

pwd

Menampilkan lokasi direktori aktif saat ini.

B. ls — Melihat isi direktori

ls

Menampilkan file dan folder di direktori aktif.

ls -l

Menampilkan informasi file dalam format lebih terperinci.

ls -a

Menampilkan file tersembunyi juga.

C. cd — Berpindah direktori

cd Documents

Masuk ke direktori Documents jika tersedia di lokasi aktif.

cd ..

Berpindah ke direktori induk.

cd ~

Kembali ke direktori home pengguna.

Tips: Gunakan pwd dan ls untuk memeriksa lokasi serta isi direktori sebelum menjalankan perintah lain.

📁 5. Perintah Mengelola File dan Folder

Perintah Fungsi Contoh
mkdir Membuat folder mkdir latihan
touch Membuat file kosong jika belum ada touch catatan.txt
cp Menyalin file cp a.txt b.txt
mv Memindahkan atau mengganti nama file mv a.txt data.txt
rm Menghapus file rm catatan.txt
rmdir Menghapus folder kosong rmdir latihan
cat Menampilkan isi file teks cat catatan.txt
Perhatian: Perintah penghapusan dapat menghilangkan data. Hindari mencoba perintah rm pada file penting atau memakai opsi penghapusan rekursif tanpa memahami akibatnya.

🔐 6. Perintah User dan Hak Akses

A. Melihat pengguna aktif

whoami

Menampilkan nama pengguna yang sedang aktif.

B. Melihat identitas dan grup

id

Menampilkan UID, GID, dan grup pengguna.

C. Mengubah hak akses file

chmod 644 catatan.txt

Memberikan izin baca dan tulis kepada pemilik, serta izin baca kepada grup dan pengguna lain.

D. Menjalankan perintah dengan hak administrator

sudo perintah

Menjalankan perintah dengan hak istimewa jika akun diizinkan menggunakan sudo. Ganti kata perintah dengan perintah yang diperlukan.

Gunakan sudo hanya saat diperlukan. Perintah dengan hak administrator dapat mengubah konfigurasi penting sistem.

📦 7. Mengelola Paket Aplikasi di Debian

Debian menggunakan APT untuk membantu mengelola paket perangkat lunak dari repositori yang dikonfigurasi.

A. Memperbarui daftar paket

sudo apt update

Memperbarui informasi paket dari repositori.

B. Memasang aplikasi

sudo apt install nama-paket

Memasang paket yang tersedia. Ganti nama-paket dengan nama paket sebenarnya.

C. Memperbarui paket yang terpasang

sudo apt upgrade

Memperbarui paket yang dapat ditingkatkan sesuai pengelolaan APT.

D. Mencari paket

apt search nama-paket

Mencari paket berdasarkan kata kunci.

Perintah instalasi atau pembaruan dapat meminta konfirmasi dan koneksi internet. Pastikan sumber paket yang digunakan tepercaya.

📊 8. Perintah Memeriksa Sistem dan Proses

A. Melihat informasi sistem

uname -a

Menampilkan informasi kernel dan sistem.

B. Memeriksa penggunaan disk

df -h

Menampilkan penggunaan ruang sistem berkas dengan ukuran yang mudah dibaca.

C. Memeriksa penggunaan memori

free -h

Menampilkan informasi penggunaan RAM dan swap.

D. Melihat proses yang berjalan

ps aux

Menampilkan daftar proses yang berjalan atau tercatat oleh sistem.

E. Memantau proses secara langsung

top

Menampilkan proses dan penggunaan sumber daya secara berkala. Tekan q untuk keluar.

🌐 9. Perintah Dasar Jaringan

A. Melihat alamat IP

ip addr

Menampilkan antarmuka jaringan dan alamat IP yang dikonfigurasi.

B. Melihat rute jaringan

ip route

Menampilkan informasi rute jaringan.

C. Menguji koneksi

ping -c 4 1.1.1.1

Mengirim empat paket uji ke alamat tersebut. Hasilnya dapat membantu memeriksa konektivitas IP, tetapi tidak selalu memastikan semua layanan jaringan berfungsi.

D. Melihat nama host

hostname

Menampilkan nama komputer pada jaringan.

Jika perintah tertentu tidak tersedia, periksa apakah paket yang menyediakan perintah tersebut sudah terpasang. Hasil jaringan juga dapat dipengaruhi firewall atau kebijakan jaringan.

⌨️ 10. Simbol Penting di Command Line

Simbol Fungsi Contoh
| Mengirim keluaran satu perintah ke perintah berikutnya ls -l | less
> Mengarahkan keluaran ke file dan mengganti isi sebelumnya echo Halo > a.txt
>> Menambahkan keluaran ke akhir file echo Halo >> a.txt
&& Menjalankan perintah berikutnya jika perintah pertama berhasil mkdir tes && cd tes
* Wildcard untuk mencocokkan nama file ls *.txt
Operator pengalihan seperti > dapat mengganti isi file tujuan. Periksa nama file sebelum menjalankan perintah.

🧪 11. Praktik Command Line Linux

Coba praktik berikut di Debian atau Ubuntu menggunakan akun biasa. Perintah ini membuat file latihan di dalam direktori home pengguna.

Langkah 1 — Periksa lokasi

pwd

Langkah 2 — Buat direktori latihan

mkdir latihan-cli

Langkah 3 — Masuk ke direktori

cd latihan-cli

Langkah 4 — Buat file teks

echo "Belajar Command Line Linux" > catatan.txt

Langkah 5 — Baca isi file

cat catatan.txt

Langkah 6 — Periksa file dan izinnya

ls -l

Langkah 7 — Salin file

cp catatan.txt salinan.txt

Langkah 8 — Periksa hasil salinan

ls
Hasil yang diharapkan: Di dalam folder latihan-cli terdapat file catatan.txt dan salinan.txt. File tersebut berisi teks yang sama.

💡 12. Tips Menggunakan Terminal

  • Gunakan tombol Tab untuk membantu melengkapi nama file atau perintah.
  • Gunakan tombol panah atas untuk melihat perintah sebelumnya.
  • Baca pesan kesalahan jika sebuah perintah gagal.
  • Periksa lokasi dengan pwd sebelum mengubah atau menghapus file.
  • Gunakan man nama-perintah untuk membaca panduan perintah jika tersedia.
  • Jangan menyalin perintah administrator dari sumber yang tidak dikenal tanpa memahaminya.
