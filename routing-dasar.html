Routing Dasar

Kenali cara router meneruskan paket data, memahami tabel routing, menentukan next hop, dan menghubungkan beberapa jaringan IP.

Layer 3IP AddressRouting Table
01 • Pengertian

Apa Itu Routing?

Routing adalah proses menentukan jalur yang digunakan paket IP untuk mencapai jaringan atau alamat tujuan. Perangkat yang menjalankan proses ini disebut router, termasuk multilayer switch yang memiliki fungsi routing.

Contoh: PC di jaringan 192.168.1.0/24 ingin mengirim data ke server di jaringan 192.168.2.0/24. Router membantu meneruskan paket menuju jaringan server.
Menentukan jalur

Memilih rute menuju alamat IP tujuan.

Meneruskan paket

Mengirim paket melalui antarmuka atau next hop yang sesuai.

Menghubungkan subnet

Memungkinkan komunikasi antarjaringan IP.

Memilih rute terbaik

Menggunakan aturan routing dan panjang prefix tujuan.

02 • Topologi

Contoh Routing Sederhana

PC-A ROUTER PC-B 192.168.1.10/24 ── G0/0 G0/1 ── 192.168.2.10/24 .1 .1 192.168.1.1 192.168.2.1

Router mempunyai dua antarmuka. G0/0 berada di jaringan 192.168.1.0/24, sedangkan G0/1 berada di jaringan 192.168.2.0/24.

PerangkatAlamat IPDefault Gateway
PC-A192.168.1.10/24192.168.1.1
Router G0/0192.168.1.1/24—
Router G0/1192.168.2.1/24—
PC-B192.168.2.10/24192.168.2.1
Karena kedua jaringan terhubung langsung ke router, router akan memiliki rute connected setelah antarmuka dikonfigurasi dengan benar dan berstatus aktif.
03 • Cara Kerja

Bagaimana Routing Bekerja?

  1. Periksa jaringan tujuan.
    Host membandingkan alamat IP tujuan dengan subnet lokalnya.
  2. Kirim ke gateway.
    Jika tujuan berada di luar subnet lokal, host mengirim paket ke default gateway.
  3. Router membaca alamat tujuan.
    Router memeriksa tabel routing untuk mencari rute yang cocok.
  4. Pilih rute.
    Router memilih kecocokan prefix paling panjang. Jika beberapa rute memiliki prefix sama, metrik dan aturan pemilihan rute ikut berperan.
  5. Teruskan paket.
    Router mengirim paket ke next hop atau antarmuka keluar yang dipilih.
04 • Tabel Routing

Mengenal Routing Table

Routing table berisi informasi tentang jaringan tujuan dan cara mencapainya.

IstilahFungsi
Destination / PrefixJaringan atau rentang alamat IP tujuan.
Next hopRouter berikutnya yang menerima paket.
Outgoing interfaceAntarmuka untuk meneruskan paket.
MetricNilai yang dipakai protokol untuk membandingkan rute.
Administrative distancePada Cisco, nilai untuk membandingkan sumber rute yang menuju prefix sama.

Perintah pemeriksaan Cisco

show ip route show ip interface brief show running-config

Huruf di depan entri tabel routing Cisco menunjukkan sumber rute. Contohnya, C berarti connected, S berarti static, dan O biasanya menunjukkan rute yang dipelajari melalui OSPF.

05 • Jenis Routing

Routing Statis dan Dinamis

Static Routing

Rute dimasukkan secara manual oleh administrator. Cocok untuk jaringan kecil atau jalur tertentu.

Dynamic Routing

Router mempelajari dan memperbarui rute menggunakan protokol routing seperti OSPF, RIP, atau EIGRP.

Selain itu, router membuat rute connected untuk jaringan yang terpasang langsung pada antarmuka aktif dan memiliki konfigurasi IP yang sesuai.

Routing berbeda dengan switching Layer 2. Switch meneruskan frame berdasarkan MAC address, sedangkan router meneruskan paket berdasarkan informasi Layer 3.
06 • Praktik Cisco

Konfigurasi Routing Antarjaringan

Contoh ini menggunakan router dengan dua antarmuka. Nama interface bisa berbeda pada perangkat atau simulator yang digunakan.

enable configure terminal interface gigabitEthernet 0/0 ip address 192.168.1.1 255.255.255.0 no shutdown exit interface gigabitEthernet 0/1 ip address 192.168.2.1 255.255.255.0 no shutdown end show ip interface brief show ip route

Jika kedua interface aktif dan alamat IP benar, jaringan yang terhubung langsung akan muncul pada tabel routing. Untuk topologi dua LAN sederhana ini, rute static belum diperlukan.

Pengujian

ping 192.168.2.10

Jalankan ping dari PC-A ke PC-B setelah mengatur IP, subnet mask, dan gateway kedua PC. Pastikan kabel, interface router, dan firewall perangkat tujuan tidak menghalangi pengujian.

07 • Troubleshooting

Jika Routing Tidak Berhasil

GejalaYang perlu diperiksa
Interface downKabel, port, status interface, dan perintah no shutdown.
Gateway salahDefault gateway host harus sesuai dengan interface router pada subnetnya.
IP atau mask salahPastikan IP dan subnet mask host serta router benar.
Rute tujuan tidak adaPeriksa routing table dan tambahkan rute yang diperlukan.
Ping gagal meskipun rute adaPeriksa rute balik, firewall, ACL, serta konektivitas Layer 2.
08 • Kuis

Uji Pemahaman Routing Dasar

Pilih satu jawaban yang benar.

1. Routing umumnya bekerja pada lapisan OSI ...

Routing IP merupakan fungsi Layer 3.

2. Apa fungsi default gateway pada PC?

Default gateway menjadi pintu keluar host menuju jaringan lain.

3. Perintah Cisco untuk melihat tabel routing IPv4 adalah ...

show ip route menampilkan tabel routing IPv4.

4. Apa arti rute connected?

Rute connected muncul dari jaringan yang terpasang langsung pada interface router aktif.

5. Apa yang dilakukan router ketika meneruskan paket?

Router menggunakan tabel routing untuk menentukan langkah penerusan paket.
09 • Ringkasan

Kesimpulan Routing Dasar

  • Routing menentukan jalur paket IP menuju tujuan.
  • Router menggunakan routing table untuk memilih rute.
  • Host menggunakan default gateway untuk mencapai subnet lain.
  • Connected route berasal dari jaringan yang terhubung langsung.
  • Static routing dikonfigurasi manual, sedangkan dynamic routing menggunakan protokol routing.
  • Pengujian harus memeriksa IP, gateway, interface, rute, dan jalur balik.
