Manajemen User & File

Pelajari cara mengelola pengguna, grup, file, direktori, dan hak akses di Linux.

🐧 Belajar Administrasi Linux

Manajemen user dan file merupakan bagian penting dalam administrasi sistem. Dengan memahami materi ini, kamu dapat mengatur siapa yang boleh masuk ke sistem, file yang dapat diakses, serta tindakan yang diizinkan bagi setiap pengguna.

📘 1. Pengertian Manajemen User & File

Manajemen user adalah proses membuat, mengatur, mengubah, dan menghapus akun pengguna dalam sistem operasi.

Manajemen file adalah proses mengelola file dan direktori, termasuk membuat, menyalin, memindahkan, menghapus, serta mengatur hak aksesnya.

Contoh penerapan: Administrator server membuat akun untuk setiap pengguna dan membatasi akses mereka agar file penting tidak dapat diubah oleh sembarang orang.

🎯 2. Tujuan Manajemen User & File

  • Mengatur akun yang dapat menggunakan sistem.
  • Membatasi akses sesuai tugas dan tanggung jawab pengguna.
  • Melindungi file dan data penting.
  • Mempermudah pengelolaan file serta direktori.
  • Mendukung keamanan dan administrasi server.
  • Mencegah perubahan data oleh pengguna yang tidak berwenang.

👤 3. Jenis Pengguna di Linux

Administrator / Root

Akun dengan hak istimewa tertinggi untuk mengelola sistem. Penggunaannya harus hati-hati karena dapat mengubah bagian penting sistem.

Pengguna Biasa

Akun untuk kegiatan sehari-hari, seperti mengelola file sendiri dan menjalankan aplikasi sesuai izin.

Akun Sistem

Akun yang digunakan oleh layanan atau proses tertentu untuk menjalankan tugas sistem.

Perintah melihat pengguna

whoami

Menampilkan nama pengguna yang sedang aktif di terminal.

who

Menampilkan pengguna yang sedang masuk ke sistem.

id

Menampilkan UID, GID, dan grup yang dimiliki pengguna saat ini.

➕ 4. Membuat dan Mengelola User

A. Membuat pengguna baru

sudo adduser siswa

Membuat akun bernama siswa pada Debian atau sistem Linux yang mendukung perintah adduser. Ikuti petunjuk untuk mengatur kata sandi dan informasi akun.

B. Mengatur kata sandi

sudo passwd siswa

Mengatur atau mengganti kata sandi akun siswa.

C. Melihat informasi pengguna

id siswa

Menampilkan identitas dan keanggotaan grup pengguna siswa.

D. Mengubah nama pengguna

sudo usermod -l siswa_baru siswa

Mengubah nama login dari siswa menjadi siswa_baru. Pastikan pengguna tidak sedang aktif dan periksa direktori home jika perlu.

E. Menghapus pengguna

sudo deluser siswa

Menghapus akun siswa pada Debian. Perintah ini tidak otomatis menghapus semua file milik pengguna.

Perhatian: Sebelum menghapus akun, pastikan file penting sudah dicadangkan dan akun tersebut memang tidak lagi diperlukan.

👥 5. Manajemen Grup Pengguna

Grup digunakan untuk mengelompokkan pengguna sehingga hak akses terhadap file atau sumber daya tertentu dapat dikelola bersama.

A. Membuat grup

sudo addgroup jaringan

Membuat grup bernama jaringan pada Debian.

B. Menambahkan pengguna ke grup

sudo usermod -aG jaringan siswa

Menambahkan siswa ke grup jaringan. Opsi -aG digunakan untuk menambahkan grup tambahan tanpa mengganti keanggotaan grup lain.

C. Melihat grup pengguna

groups siswa

D. Menghapus grup

sudo delgroup jaringan

Menghapus grup jaringan jika grup tersebut sudah tidak diperlukan dan tidak sedang digunakan sebagai grup utama pengguna.

📁 6. Mengelola File dan Direktori

Perintah Fungsi Contoh
pwd Menampilkan direktori aktif pwd
ls Melihat isi direktori ls -l
cd Berpindah direktori cd Documents
mkdir Membuat direktori mkdir latihan
touch Membuat file kosong jika belum ada touch catatan.txt
cp Menyalin file cp a.txt b.txt
mv Memindahkan atau mengganti nama mv a.txt data.txt
rm Menghapus file rm catatan.txt
rmdir Menghapus direktori kosong rmdir latihan
Hati-hati saat menggunakan perintah penghapusan. Perintah rm dapat menghapus file tanpa memindahkannya ke tempat sampah. Periksa nama dan lokasi file sebelum menjalankannya.

🔐 7. Hak Akses File di Linux

Linux memiliki tiga kategori utama pengguna dalam pengaturan izin file:

  • Owner (u): pemilik file.
  • Group (g): grup yang memiliki akses ke file.
  • Others (o): pengguna lain di luar pemilik dan grup.

Jenis izin yang umum digunakan:

Izin Simbol Arti Nilai angka
Read r Membaca file atau melihat isi direktori 4
Write w Mengubah file atau isi direktori 2
Execute x Menjalankan file atau menelusuri direktori 1

Contoh tampilan izin

-rw-r--r-- 1 siswa siswa 120 Oct 10 catatan.txt

Bagian -rw-r--r-- menunjukkan bahwa pemilik dapat membaca dan mengubah file, sedangkan grup dan pengguna lain hanya dapat membacanya.

Melihat hak akses file

ls -l

Mengubah hak akses dengan chmod

chmod 644 catatan.txt

Pemilik mendapat izin baca dan tulis, sedangkan grup serta pengguna lain mendapat izin baca.

chmod 755 skrip.sh

Pemilik mendapat izin baca, tulis, dan eksekusi; grup serta pengguna lain mendapat izin baca dan eksekusi.

Mengubah pemilik file dengan chown

sudo chown siswa:siswa catatan.txt

Mengubah pemilik dan grup file menjadi siswa.

Ingat: Nilai chmod merupakan penjumlahan izin. Contohnya, 7 = 4 + 2 + 1 (baca, tulis, eksekusi), sedangkan 5 = 4 + 1 (baca dan eksekusi).

🗂️ 8. Lokasi File Penting di Linux

  • /home — lokasi direktori home banyak pengguna biasa.
  • /root — direktori home untuk akun root.
  • /etc/passwd — informasi dasar akun pengguna.
  • /etc/shadow — informasi autentikasi dan hash kata sandi yang dilindungi aksesnya.
  • /etc/group — informasi grup pengguna.
  • /tmp — lokasi untuk file sementara.
  • /var/log — lokasi banyak file log sistem dan layanan.
File konfigurasi akun dan autentikasi merupakan bagian penting sistem. Jangan mengeditnya secara langsung tanpa memahami format dan dampaknya.

🧪 9. Praktik Sederhana di Debian

Praktik berikut cocok dilakukan pada mesin virtual Debian agar aman untuk pembelajaran.

Langkah 1 — Buat pengguna latihan

sudo adduser siswa

Langkah 2 — Buat folder latihan

mkdir ~/latihan-file

Langkah 3 — Masuk ke folder

cd ~/latihan-file

Langkah 4 — Buat file

touch catatan.txt

Langkah 5 — Periksa file

ls -l

Langkah 6 — Ubah izin file

chmod 640 catatan.txt

Langkah 7 — Periksa hasil

ls -l catatan.txt

Jika perintah berhasil, izin file akan menunjukkan bahwa pemilik dapat membaca dan menulis, grup dapat membaca, dan pengguna lain tidak memiliki izin baca, tulis, atau eksekusi.

Catatan: Jalankan perintah pembuatan file dan folder sebagai pengguna biasa. Jika terminal belum berada di akun siswa, folder latihan akan dibuat di direktori home pengguna yang sedang aktif.
