Dynamic Routing

Pelajari cara router bertukar informasi rute secara otomatis, mengenali protokol routing, memahami konvergensi, dan mencoba konfigurasi OSPF dasar.

OSPFRIPEIGRP
01 • Pengertian

Apa Itu Dynamic Routing?

Dynamic routing adalah metode routing ketika router menggunakan protokol routing untuk bertukar informasi jaringan, mempelajari rute, dan memperbarui tabel routing sesuai perubahan topologi.

Contoh: Jika sebuah link antarruter gagal, protokol routing dapat menghitung atau memilih jalur alternatif jika jalur tersebut tersedia dan informasi jaringan sudah diperbarui.
Pertukaran informasi

Router berbagi informasi jaringan melalui protokol yang sama atau kompatibel.

Pembaruan rute

Rute dapat diperbarui ketika topologi berubah.

Skalabilitas

Lebih mudah dikelola pada topologi yang berkembang.

Pemilihan jalur

Protokol menggunakan algoritma dan metriknya untuk memilih rute.

02 • Cara Kerja

Proses Dynamic Routing

  1. Router diaktifkan.
    Administrator mengonfigurasi protokol routing pada interface atau jaringan yang diperlukan.
  2. Router menemukan tetangga.
    Protokol seperti OSPF membentuk adjacency dengan router tetangga yang memenuhi persyaratan.
  3. Informasi jaringan dipertukarkan.
    Router membagikan informasi sesuai mekanisme protokol.
  4. Rute dihitung dan dipilih.
    Router menggunakan algoritma, metrik, dan aturan pemilihan rute protokol.
  5. Tabel routing diperbarui.
    Rute yang memenuhi syarat dipasang ke tabel routing. Perubahan topologi dapat memicu perhitungan ulang.
Dynamic routing tidak berarti semua rute pasti tersedia otomatis. Protokol, interface, pengalamatan, dan kebijakan routing harus dikonfigurasi dengan benar.
03 • Jenis Protokol

Protokol Dynamic Routing

ProtokolKarakteristik
RIPDistance-vector; menggunakan jumlah hop sebagai metrik dan memiliki batas maksimum 15 hop yang dapat dijangkau.
OSPFLink-state; menghitung jalur berdasarkan biaya (cost), umum digunakan pada jaringan internal.
EIGRPAdvanced distance-vector; menggunakan algoritma DUAL. Dukungan dan fitur bergantung pada platform.
BGPPath-vector; digunakan untuk pertukaran rute antar-autonomous system, termasuk routing Internet.
Untuk latihan awal di Cisco Packet Tracer, OSPF atau RIP dapat dipakai jika tersedia pada perangkat simulasi. Contoh konfigurasi di halaman ini menggunakan OSPF.
04 • OSPF Dasar

Contoh Topologi OSPF

LAN A LINK LAN B 192.168.1.0/24 192.168.2.0/24 | | Router A -------- 10.0.0.1/30 ── 10.0.0.2/30 -------- Router B | | PC-A PC-B

Router A memiliki LAN 192.168.1.0/24 dan Router B memiliki LAN 192.168.2.0/24. Kedua router terhubung melalui jaringan 10.0.0.0/30.

Pastikan interface sudah dikonfigurasi menggunakan alamat IP yang sesuai dan aktif sebelum mengaktifkan OSPF.

05 • Konfigurasi Cisco

Konfigurasi OSPF Area 0

Contoh menggunakan process ID 1 dan area 0. Network statement di bawah memakai wildcard mask untuk mencocokkan interface yang ingin diiklankan.

Router A

enable configure terminal router ospf 1 network 192.168.1.0 0.0.0.255 area 0 network 10.0.0.0 0.0.0.3 area 0 end show ip ospf neighbor show ip route ospf

Router B

enable configure terminal router ospf 1 network 192.168.2.0 0.0.0.255 area 0 network 10.0.0.0 0.0.0.3 area 0 end show ip ospf neighbor show ip route ospf
Perhatikan: Wildcard mask 0.0.0.255 mencocokkan jaringan /24, sedangkan 0.0.0.3 mencocokkan jaringan /30. Sintaks dapat berbeda menurut platform dan versi perangkat lunak.
06 • Verifikasi

Memeriksa OSPF

show ip ospf neighbor show ip protocols show ip route show ip route ospf show ip interface brief
  1. Periksa neighbor.
    Router A dan B seharusnya membentuk adjacency jika pengaturan dan koneksi sesuai.
  2. Periksa rute OSPF.
    Pastikan rute LAN seberang muncul pada tabel routing.
  3. Uji konektivitas.
    Lakukan ping antar-PC setelah gateway pada masing-masing PC dikonfigurasi.
Pada Cisco, rute OSPF IPv4 umumnya ditandai huruf O di tabel routing. Rute yang diterima bergantung pada kondisi adjacency dan konfigurasi jaringan.

Evaluasi Dynamic Routing

KelebihanKekurangan

Mendukung jaringan dengan banyak router.Menggunakan sumber daya CPU, memori, dan bandwidth.

08 • Troubleshooting

OSPF Tidak Berjalan?

GejalaHal yang diperiksa
Neighbor tidak munculAlamat IP, area, timer, autentikasi, konektivitas, dan konfigurasi OSPF pada interface.
Rute LAN tidak munculNetwork statement, interface yang cocok, status link, dan informasi yang diiklankan.
Neighbor belum FULLPeriksa kondisi adjacency, jenis jaringan OSPF, serta pesan diagnostik perangkat.
Rute ada tetapi ping gagalPeriksa gateway host, rute balik, ACL, firewall, dan koneksi Layer 2.
09 • Kuis

Uji Pemahaman Dynamic Routing

Pilih satu jawaban yang benar.

1. Dynamic routing menggunakan ...

Protokol routing memungkinkan router bertukar informasi dan mempelajari rute.

2. OSPF termasuk protokol jenis ...

OSPF merupakan protokol routing link-state.

3. Perintah untuk melihat neighbor OSPF pada Cisco adalah ...

Perintah tersebut menampilkan informasi tetangga OSPF.

4. Apa arti konvergensi dalam dynamic routing?

Konvergensi adalah proses router menyesuaikan informasi routing setelah perubahan.

5. Apa kelebihan dynamic routing dibanding semua rute diketik manual?

Dynamic routing dapat menyesuaikan rute ketika informasi topologi berubah.
10 • Ringkasan

Kesimpulan Dynamic Routing

  • Dynamic routing mempelajari rute menggunakan protokol routing.
  • RIP, OSPF, EIGRP, dan BGP memiliki mekanisme serta tujuan penggunaan berbeda.
  • OSPF merupakan protokol link-state yang menggunakan cost untuk pemilihan jalur.
  • Neighbor dan tabel routing perlu diperiksa saat troubleshooting.
  • Dynamic routing memudahkan pengelolaan jaringan yang berkembang, tetapi tetap membutuhkan konfigurasi yang tepat.
