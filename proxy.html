Proxy Server

Pelajari forward proxy, reverse proxy, kontrol akses, dan praktik dasar Squid pada Debian.

Forward ProxySquidKontrol Akses
01 • PENGENALAN

Apa Itu Proxy Server?

Proxy server menjadi perantara antara klien dan server tujuan. Proxy dapat digunakan untuk kontrol akses, pencatatan, penyaringan, dan pada konfigurasi tertentu caching konten.

↔️ Forward ProxyPerantara klien menuju server tujuan.
🛡️ Reverse ProxyMenerima permintaan dan meneruskannya ke backend.
📋 Access ControlMembatasi akses berdasarkan aturan.
⚡ CacheMenyimpan konten tertentu untuk digunakan kembali.
02 • JENIS PROXY

Forward Proxy dan Reverse Proxy

JenisPeranContoh
Forward proxyMelayani permintaan klien ke tujuan.Proxy HTTP kantor/lab.
Reverse proxyMenerima permintaan lalu meneruskan ke backend.Proxy di depan web server.

Proxy tidak otomatis membuat pengguna anonim atau koneksi aman. Hasilnya bergantung pada konfigurasi dan kebijakan jaringan.

03 • CARA KERJA

Alur Kerja Forward Proxy

1
Klien mengirim permintaan

Aplikasi dikonfigurasi menggunakan proxy.

2
Proxy memeriksa aturan

Proxy mengevaluasi tujuan dan kebijakan akses.

3
Permintaan diteruskan

Jika diizinkan, proxy menghubungi server tujuan.

4
Respons dikembalikan

Proxy meneruskan respons ke klien.

Squid sering menggunakan port 3128 untuk HTTP proxy, tetapi port dapat diubah.
04 • PRAKTIK DEBIAN

Instal Proxy Server Squid

Contoh berikut membuat forward proxy untuk jaringan laboratorium. Ganti subnet dengan jaringan yang benar.

1. Instal Squid

sudo apt update
sudo apt install squid

2. Cadangkan dan edit konfigurasi

sudo cp /etc/squid/squid.conf /etc/squid/squid.conf.bak
sudo nano /etc/squid/squid.conf

Tambahkan aturan yang sesuai sebelum aturan penolakan umum:

http_port 3128
acl labnet src 192.168.10.0/24
http_access allow labnet
http_access deny all

Periksa file yang ada agar aturan tidak bertabrakan. Letakkan ACL jaringan lab sebelum http_access deny all.

3. Periksa konfigurasi

sudo squid -k parse

4. Restart layanan

sudo systemctl restart squid
sudo systemctl status squid

5. Uji dari klien

curl -x http://192.168.10.2:3128 http://example.com

Ganti IP dengan alamat server proxy. Pastikan klien dapat menjangkau server dan firewall mengizinkan port proxy.

Contoh ACL mengizinkan subnet lab saja. Jangan membuka proxy untuk semua alamat internet karena open proxy dapat disalahgunakan.

Troubleshooting Proxy Server

MasalahPemeriksaan
Proxy tidak bisa dihubungiIP, layanan Squid, port, dan firewall.
Access DeniedACL, urutan aturan, dan subnet klien.
Website gagal dibukaDNS, koneksi keluar, dan kebijakan proxy.
Konfigurasi gagalSintaks konfigurasi Squid.
sudo systemctl status squid
sudo squid -k parse
sudo journalctl -u squid --no-pager -n 40
sudo tail -n 40 /var/log/squid/access.log
