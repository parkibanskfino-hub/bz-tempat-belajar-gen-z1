Belajar Subnetting

Pahami cara membagi jaringan IP menjadi beberapa subnet, menghitung network ID, broadcast address, subnet mask, dan jumlah host.

IPv4 CIDR Perhitungan IP
01 • Pengertian

Apa Itu Subnetting?

Subnetting adalah proses membagi satu jaringan IP menjadi beberapa jaringan yang lebih kecil, disebut subnet. Tujuannya antara lain mengatur alamat IP, memisahkan kelompok perangkat, dan mempermudah pengelolaan jaringan.

Contoh: Jaringan 192.168.1.0/24 dapat dibagi menjadi beberapa subnet yang lebih kecil, misalnya empat subnet /26.
Network ID

Menunjukkan identitas jaringan atau subnet.

Host

Alamat yang dapat digunakan perangkat dalam subnet.

Broadcast

Alamat untuk mengirim paket ke semua host pada subnet IPv4 tersebut.

Subnet Mask

Menentukan bagian network dan host dari alamat IPv4.

02 • Konsep Dasar

Network dan Host

Alamat IPv4 memiliki 32 bit. Sebagian bit digunakan untuk bagian jaringan, sedangkan sisanya digunakan untuk bagian host. Prefix menunjukkan banyaknya bit network.

Alamat IP : 192.168.1.10/24 Prefix : 24 bit network Host bits : 32 - 24 = 8 bit Subnet mask: 255.255.255.0

Dalam contoh tersebut, 24 bit pertama menunjukkan network. Delapan bit sisanya digunakan untuk mengidentifikasi alamat di dalam subnet.

Network ID dan broadcast address bukan alamat host biasa yang dapat diberikan ke komputer pada subnet IPv4 tradisional.
03 • Subnet Mask

Hubungan Prefix dan Subnet Mask

Prefix CIDR ditulis dengan tanda garis miring, seperti /24. Semakin besar angka prefix, semakin banyak bit yang digunakan untuk network dan semakin sedikit bit untuk host.

04 • Rumus

Rumus Dasar Subnetting

Jumlah bit host:
32 - prefix
Total alamat IPv4:
2^(jumlah bit host)
Jumlah host yang dapat digunakan:
2^(jumlah bit host) - 2

Contoh prefix /26

Jumlah bit host = 32 - 26 = 6 Total alamat = 2^6 = 64 Host biasa = 64 - 2 = 62

Jadi, satu subnet /26 memiliki 64 alamat IPv4 secara keseluruhan dan biasanya 62 alamat host yang dapat digunakan.

05 • Contoh Lengkap

Menghitung Subnet /26

Diketahui alamat jaringan 192.168.1.0/26. Tentukan subnet mask, network ID, broadcast address, dan rentang host.

  1. Tentukan subnet mask.
    Prefix /26 menghasilkan mask 255.255.255.192.
  2. Hitung jumlah alamat.
    32 − 26 = 6 bit host. Maka total alamat adalah 2⁶ = 64.
  3. Hitung ukuran blok.
    256 − 192 = 64. Pada oktet terakhir, blok subnet bertambah setiap 64.
  4. Tentukan network ID.
    Blok pertama dimulai dari 192.168.1.0.
  5. Tentukan broadcast.
    Blok pertama berakhir di 192.168.1.63.
  6. Tentukan rentang host.
    Alamat host yang dapat digunakan adalah 192.168.1.1 sampai 192.168.1.62.

06 • Pembagian Subnet

Membagi Jaringan /24 Menjadi /26

Jaringan 192.168.1.0/24 memiliki 256 alamat. Jika dibagi menjadi subnet /26, ukuran setiap blok adalah 64 alamat sehingga terbentuk empat subnet.

07 • Contoh /27

Menghitung Subnet /27

Diketahui alamat 192.168.10.70/27. Karena prefix /27 memiliki ukuran blok 32 pada oktet terakhir, bloknya dimulai pada 0, 32, 64, 96, dan seterusnya.

IP contoh : 192.168.10.70/27 Subnet mask : 255.255.255.224 Ukuran blok : 256 - 224 = 32 Blok yang sesuai: 64 sampai 95 Network ID : 192.168.10.64 Host pertama : 192.168.10.65 Host terakhir : 192.168.10.94 Broadcast : 192.168.10.95 Total alamat : 32 Host biasa : 30

Alamat 192.168.10.70 termasuk subnet 192.168.10.64/27 karena berada di antara network ID dan broadcast subnet tersebut.

08 • Langkah Cepat

Trik Menghitung Subnet

  1. Perhatikan prefix.
    Contoh: /26.
  2. Cari subnet mask.
    /26 = 255.255.255.192.
  3. Hitung ukuran blok.
    256 − 192 = 64.
  4. Cari blok yang memuat IP.
    Untuk oktet 70, blok 64–127 adalah blok yang sesuai.
  5. Tentukan network dan broadcast.
    Network adalah awal blok; broadcast adalah akhir blok.
  6. Tentukan host.
    Untuk subnet biasa, alamat di antara network dan broadcast adalah rentang host.
09 • Kuis

Uji Pemahaman Subnetting

Pilih satu jawaban yang benar untuk setiap pertanyaan.

1. Apa fungsi subnetting?

Subnetting membagi satu jaringan IP menjadi beberapa jaringan yang lebih kecil.

2. Subnet mask dari prefix /26 adalah ...

Prefix /26 sama dengan subnet mask 255.255.255.192.

3. Berapa total alamat pada subnet /27?

/27 menyisakan 5 bit host, jadi 2⁵ = 32 alamat.

4. Berapa host biasa yang dapat digunakan pada subnet /26?

/26 memiliki 64 alamat; untuk subnet biasa, 64 − 2 = 62 host.

5. Network ID dari 192.168.10.70/27 adalah ...

Subnet /27 memiliki blok 32. Alamat .70 masuk ke blok .64–.95, sehingga network ID-nya .64.
10 • Ringkasan

Kesimpulan Subnetting

  • Subnetting membagi jaringan IP menjadi jaringan yang lebih kecil.
  • Prefix menunjukkan jumlah bit network.
  • Jumlah bit host IPv4 = 32 − prefix.
  • Total alamat = 2 pangkat jumlah bit host.
  • Untuk subnet IPv4 biasa, host yang dapat digunakan umumnya total alamat dikurangi dua.
  • Network ID adalah awal blok dan broadcast adalah akhir blok pada subnet IPv4 biasa.
  • Ukuran blok membantu menentukan rentang setiap subnet.
