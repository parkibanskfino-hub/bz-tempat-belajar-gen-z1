DHCP Server

Pelajari cara kerja DHCP Server, proses pemberian IP address otomatis, serta konfigurasi DHCP pada Debian/Linux dan perangkat jaringan Cisco.

Dasar Jaringan IP Address Konfigurasi Server
01 • PENGENALAN

Apa Itu DHCP Server?

DHCP (Dynamic Host Configuration Protocol) adalah protokol jaringan yang digunakan untuk memberikan konfigurasi IP address secara otomatis kepada perangkat klien.

DHCP Server membantu administrator jaringan karena tidak perlu mengatur alamat IP satu per satu pada setiap komputer.

📡 IP Address Alamat IP diberikan secara otomatis kepada klien.
🧭 Subnet Mask Menentukan bagian jaringan dan bagian host.
🚪 Default Gateway Alamat perangkat untuk menuju jaringan lain.
🌍 DNS Server Membantu menerjemahkan nama domain menjadi alamat IP.
02 • FUNGSI

Fungsi DHCP Server

  • Memberikan IP address secara otomatis kepada klien.
  • Mengurangi kesalahan pengaturan IP secara manual.
  • Mengirimkan subnet mask, gateway, dan DNS sesuai konfigurasi.
  • Mengelola peminjaman alamat IP melalui mekanisme lease.
  • Memudahkan pengelolaan jaringan dengan banyak perangkat.
Contoh: Ketika laptop terhubung ke Wi-Fi, DHCP Server dapat memberikan IP address tanpa perlu mengaturnya secara manual.
03 • KOMPONEN

Komponen DHCP

Komponen Penjelasan
DHCP Server Perangkat yang menyediakan konfigurasi IP.
DHCP Client Perangkat yang meminta konfigurasi IP.
IP Pool Rentang alamat IP yang dapat diberikan.
Lease Time Durasi peminjaman alamat IP oleh klien.
Reservation Pengaturan agar klien tertentu mendapat IP tertentu berdasarkan identitasnya.
04 • CARA KERJA

Proses DORA

DHCP menggunakan empat tahap utama yang dikenal dengan istilah DORA.

1
Discover

Klien mencari DHCP Server yang tersedia di jaringan.

2
Offer

Server menawarkan alamat IP beserta konfigurasi jaringan.

3
Request

Klien meminta alamat IP yang ditawarkan oleh server.

4
Acknowledge

Server mengonfirmasi pemberian alamat IP kepada klien.

DORA merupakan singkatan dari Discover, Offer, Request, dan Acknowledge. DHCP untuk IPv4 umumnya menggunakan UDP port 67 pada server dan port 68 pada klien.
05 • TOPOLOGI

Contoh Topologi DHCP

       [ DHCP Server ]
        192.168.10.2
              |
              |
           [ Switch ]
           /        \
          /          \
       [ PC 1 ]     [ PC 2 ]
       DHCP Client  DHCP Client

   Gateway : 192.168.10.1
   Network : 192.168.10.0/24

Dalam contoh ini, DHCP Server memberikan alamat IP kepada PC 1 dan PC 2 melalui switch. Server dan klien harus berada pada jaringan yang dapat saling menjangkau.

Jika DHCP Server berada di VLAN atau subnet berbeda, biasanya diperlukan DHCP relay pada perangkat Layer 3 agar permintaan DHCP dapat diteruskan ke server.
06 • PRAKTIK LINUX

Konfigurasi DHCP Server di Debian

Contoh berikut menggunakan Debian dengan layanan isc-dhcp-server. Pastikan alamat IP server sudah diatur secara statis dan sesuaikan nama interface dengan perangkatmu.

Langkah 1 — Periksa interface

TERMINAL
ip -br a

Perintah tersebut menampilkan nama interface dan alamat IP. Pada contoh, interface server adalah ens33. Nama interface pada komputermu mungkin berbeda.

Langkah 2 — Instal DHCP Server

TERMINAL
sudo apt update
sudo apt install isc-dhcp-server

Langkah 3 — Atur interface DHCP

Buka file konfigurasi interface:

TERMINAL
sudo nano /etc/default/isc-dhcp-server

Isi interface IPv4 sesuai perangkat, misalnya:

INTERFACESv4="ens33"

Simpan file, lalu keluar dari editor.

Langkah 4 — Atur rentang IP

Buka konfigurasi utama:

TERMINAL
sudo nano /etc/dhcp/dhcpd.conf

Tambahkan konfigurasi contoh berikut:

DHCPD.CONF
default-lease-time 600;
max-lease-time 7200;
authoritative;

subnet 192.168.10.0 netmask 255.255.255.0 {
    range 192.168.10.100 192.168.10.200;
    option subnet-mask 255.255.255.0;
    option routers 192.168.10.1;
    option domain-name-servers 8.8.8.8 1.1.1.1;
}
Penting: Contoh di atas mengasumsikan jaringan 192.168.10.0/24, gateway 192.168.10.1, dan server memiliki IP statis di subnet tersebut. Pastikan alamat gateway benar-benar digunakan oleh router atau perangkat Layer 3. Jangan sampai rentang IP DHCP bertabrakan dengan alamat statis.

Langkah 5 — Periksa konfigurasi

TERMINAL
sudo dhcpd -t -cf /etc/dhcp/dhcpd.conf

Perintah ini memeriksa sintaks konfigurasi DHCP. Jika ada kesalahan, perbaiki sesuai pesan yang ditampilkan.

Langkah 6 — Aktifkan layanan

TERMINAL
sudo systemctl restart isc-dhcp-server
sudo systemctl status isc-dhcp-server

Langkah 7 — Uji dari klien

Pada klien Linux, pilih interface yang benar lalu minta alamat IP menggunakan DHCP:

TERMINAL KLIEN
sudo dhclient -v ens33
ip -br a

Ganti ens33 dengan interface klien yang digunakan. Perintah dhclient harus tersedia pada sistem klien.

07 • PRAKTIK CISCO

Contoh DHCP Server pada Router Cisco

Router Cisco juga dapat bertindak sebagai DHCP Server untuk jaringan yang terhubung langsung dengannya.

CISCO IOS
enable
configure terminal

interface gigabitEthernet 0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
exit

ip dhcp excluded-address 192.168.10.1 192.168.10.99

ip dhcp pool LAN
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8 1.1.1.1
exit

end
show ip dhcp binding

Contoh tersebut mengecualikan alamat 192.168.10.1 sampai 192.168.10.99, sehingga pool dapat memberikan alamat mulai dari 192.168.10.100 hingga 192.168.10.254.

Nama interface router dapat berbeda, misalnya GigabitEthernet0/0 atau FastEthernet0/0. Sesuaikan dengan perangkat atau simulator yang digunakan.
08 • TROUBLESHOOTING

Masalah DHCP yang Sering Terjadi

Masalah Penyebab atau pemeriksaan
Klien tidak mendapat IP Periksa layanan DHCP, kabel, VLAN, dan interface.
IP tidak sesuai subnet Periksa network dan range pada konfigurasi.
Alamat IP bertabrakan Periksa IP statis dan rentang DHCP.
Klien beda VLAN gagal Periksa DHCP relay dan routing Layer 3.
Klien mendapat IP tetapi tidak internet Periksa gateway, routing, DNS, dan koneksi internet.

Perintah pemeriksaan Debian

sudo systemctl status isc-dhcp-server
sudo journalctl -u isc-dhcp-server --no-pager -n 50
ip -br a
