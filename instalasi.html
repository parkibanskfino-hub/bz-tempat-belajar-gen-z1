Instalasi Sistem Operasi

Pelajari cara memasang, mengatur, dan memeriksa sistem operasi komputer.

💻 Selamat Datang di Materi Instalasi OS

Sistem operasi adalah perangkat lunak utama yang mengatur kerja komputer. Pada materi ini, kamu akan belajar persiapan instalasi, langkah pemasangan Windows dan Debian, penggunaan VirtualBox, serta pemeriksaan setelah instalasi.

📘 1. Pengertian Sistem Operasi

Sistem operasi atau Operating System (OS) adalah perangkat lunak yang mengelola perangkat keras dan menyediakan layanan bagi aplikasi. Sistem operasi membantu komputer menjalankan program, mengatur file, mengelola memori, serta mengatur perangkat masukan dan keluaran.

Contoh sistem operasi

🪟 Windows

Sistem operasi yang banyak digunakan pada komputer pribadi, sekolah, dan kantor.

🐧 Linux

Sistem operasi berbasis kernel Linux dengan berbagai distribusi, seperti Debian dan Ubuntu.

🍎 macOS

Sistem operasi untuk komputer Mac dari Apple.

🎯 2. Tujuan Instalasi Sistem Operasi

  • Menyiapkan komputer agar dapat digunakan.
  • Menyediakan lingkungan untuk menjalankan aplikasi.
  • Mengelola perangkat keras dan penyimpanan.
  • Memasang sistem operasi sesuai kebutuhan pengguna.
  • Menyiapkan komputer untuk kegiatan belajar dan administrasi server.
  • Mengganti atau memulihkan sistem dengan metode yang sesuai.

🧰 3. Peralatan dan Persiapan

💿 File ISO

File citra media instalasi sistem operasi yang diperoleh dari sumber resmi.

🔌 Flashdisk Bootable

Media USB yang disiapkan agar komputer dapat memulai proses instalasi.

💾 Penyimpanan

SSD atau HDD dengan kapasitas yang memenuhi persyaratan sistem operasi.

⚙️ Komputer

Perangkat yang memenuhi persyaratan prosesor, RAM, dan perangkat keras lainnya.

Checklist sebelum instalasi

  • Cadangkan file penting.
  • Periksa spesifikasi minimum sistem operasi.
  • Pastikan file ISO berasal dari sumber tepercaya.
  • Siapkan koneksi internet jika diperlukan.
  • Periksa kompatibilitas mode boot UEFI atau Legacy.
  • Pastikan media instalasi dapat digunakan.
⚠️ Penting: Memformat atau menghapus partisi dapat menyebabkan kehilangan data. Periksa disk dan partisi dengan teliti sebelum melanjutkan instalasi.

🪟 4. Langkah Instalasi Windows

1

Siapkan media instalasi

Unduh media instalasi Windows dari sumber resmi dan buat USB instalasi menggunakan alat yang sesuai.

2

Boot dari USB

Hubungkan USB ke komputer, lalu pilih media tersebut melalui menu boot perangkat.

3

Atur bahasa dan keyboard

Pilih bahasa, format waktu, dan metode input keyboard sesuai kebutuhan.

4

Mulai instalasi

Pilih opsi instalasi yang tersedia dan ikuti instruksi pada layar.

5

Pilih disk dan partisi

Tentukan lokasi instalasi dengan benar. Pastikan kamu memahami partisi yang dipilih sebelum melakukan perubahan.

6

Tunggu proses selesai

Installer akan menyalin file dan menyiapkan sistem. Komputer dapat melakukan restart beberapa kali.

7

Atur konfigurasi awal

Ikuti petunjuk untuk mengatur wilayah, akun pengguna, jaringan, dan pengaturan privasi.

8

Periksa hasil instalasi

Setelah masuk ke desktop, periksa koneksi jaringan, driver, pembaruan sistem, dan fungsi perangkat.

🐧 5. Langkah Instalasi Debian Linux

Debian merupakan distribusi Linux yang banyak digunakan untuk belajar administrasi sistem, jaringan, dan server.

1

Unduh ISO Debian

Gunakan file instalasi dari situs resmi Debian.

2

Mulai dari media instalasi

Boot komputer dari USB atau hubungkan ISO ke mesin virtual.

3

Pilih metode instalasi

Pilih Install atau Graphical Install jika tersedia pada media instalasi yang digunakan.

4

Atur bahasa dan jaringan

Tentukan bahasa, lokasi, keyboard, nama komputer, dan pengaturan jaringan.

5

Atur akun pengguna

Ikuti petunjuk installer untuk membuat akun dan mengatur kata sandi dengan aman.

6

Atur partisi disk

Pilih skema partisi sesuai kebutuhan. Untuk latihan pemula, mesin virtual dapat mengurangi risiko terhadap data komputer utama.

7

Pilih perangkat lunak

Pilih lingkungan desktop atau paket perangkat lunak yang dibutuhkan.

8

Selesaikan instalasi

Ikuti petunjuk pemasangan bootloader, selesaikan proses, lalu restart dan masuk ke Debian.

🖥️ 6. Instalasi Sistem Operasi dengan VirtualBox

VirtualBox adalah aplikasi virtualisasi yang memungkinkan kita menjalankan sistem operasi di dalam mesin virtual.

  1. Pasang VirtualBox dari situs resminya.
  2. Unduh file ISO Windows atau Linux.
  3. Buka VirtualBox dan klik New.
  4. Masukkan nama mesin virtual dan pilih file ISO.
  5. Atur RAM, CPU, dan kapasitas disk virtual sesuai kemampuan komputer.
  6. Jalankan mesin virtual.
  7. Ikuti langkah instalasi sistem operasi di dalam mesin virtual.
  8. Setelah selesai, restart mesin virtual dan periksa sistem.
Keuntungan VirtualBox: Kamu dapat berlatih memasang sistem operasi tanpa harus langsung mengubah partisi pada komputer utama.

🛠️ 8. Masalah yang Sering Terjadi

USB tidak terdeteksi saat boot

Periksa apakah media instalasi dibuat dengan benar, terdeteksi perangkat, dan sesuai dengan mode boot yang digunakan.

File ISO tidak dapat digunakan

Unduh ulang dari sumber resmi dan periksa integritas file jika informasi checksum tersedia.

Disk tidak terdeteksi

Periksa kompatibilitas perangkat penyimpanan, pengaturan firmware, dan driver yang diperlukan.

Komputer tidak dapat terhubung ke internet

Periksa adaptor jaringan, koneksi Wi-Fi atau kabel, konfigurasi IP, dan driver jaringan.

Komputer berjalan lambat

Periksa penggunaan RAM, kapasitas disk, pembaruan sistem, dan aplikasi yang berjalan di latar belakang.

✅ 9. Pemeriksaan Setelah Instalasi

  • Pastikan sistem operasi dapat melakukan boot dengan normal.
  • Periksa tanggal, waktu, bahasa, dan keyboard.
  • Pastikan jaringan dapat berfungsi.
  • Periksa driver dan perangkat yang terdeteksi.
  • Lakukan pembaruan keamanan yang diperlukan.
  • Periksa akun pengguna dan keamanan kata sandi.
  • Pasang aplikasi yang dibutuhkan.
  • Pastikan data penting sudah dicadangkan.
