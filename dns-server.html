DNS Server

Pelajari cara kerja DNS, proses penerjemahan nama domain menjadi alamat IP, serta konfigurasi DNS Server menggunakan Debian dan BIND9.

Domain Name System Debian Linux BIND9
01 • PENGENALAN

Apa Itu DNS Server?

DNS (Domain Name System) adalah sistem yang menerjemahkan nama domain, seperti example.com, menjadi alamat IP yang digunakan perangkat untuk berkomunikasi melalui jaringan.

DNS memudahkan pengguna karena mereka tidak perlu menghafal alamat IP setiap server yang ingin diakses.

🌐 Nama Domain Nama yang mudah diingat, seperti example.com.
🔢 IP Address Alamat numerik yang digunakan perangkat dalam jaringan.
🖥️ DNS Server Mencari atau memberikan informasi terkait nama domain.
📋 DNS Record Data yang menyimpan informasi domain dan alamatnya.
02 • FUNGSI

Fungsi DNS Server

  • Menerjemahkan nama domain menjadi alamat IP.
  • Membantu perangkat menemukan server tujuan.
  • Menyimpan informasi domain melalui DNS record.
  • Mendukung layanan seperti website dan email.
  • Menyediakan cache untuk mempercepat pencarian DNS berikutnya.
Contoh: Saat membuka sebuah website menggunakan nama domain, perangkat dapat meminta DNS untuk mengetahui alamat IP website tersebut.
03 • DNS RECORD

Jenis-Jenis DNS Record

Record Fungsi
A Menghubungkan nama domain ke alamat IPv4.
AAAA Menghubungkan nama domain ke alamat IPv6.
CNAME Membuat alias untuk nama domain lain.
MX Menentukan server penerima email suatu domain.
NS Menunjukkan name server yang berwenang untuk zona DNS.
PTR Digunakan untuk pencarian balik dari IP ke nama.
TXT Menyimpan informasi teks, misalnya SPF untuk email.
04 • CARA KERJA

Bagaimana DNS Bekerja?

1
Pengguna memasukkan domain

Contohnya, pengguna mengetik example.com pada browser.

2
Perangkat memeriksa cache

Perangkat memeriksa apakah informasi domain sudah tersimpan.

3
Resolver mencari alamat IP

Jika diperlukan, resolver melakukan pencarian ke DNS yang sesuai.

4
Alamat IP ditemukan

Hasil pencarian dikembalikan kepada klien untuk mengakses server tujuan.

DNS biasanya menggunakan UDP port 53 untuk kueri biasa dan juga dapat menggunakan TCP port 53, misalnya untuk transfer zona atau respons tertentu yang membutuhkan TCP.
05 • TOPOLOGI

Contoh Topologi DNS Server

       [ DNS Server Debian ]
          192.168.10.2
                 |
                 |
              [ Switch ]
              /        \
             /          \
          [ PC 1 ]    [ PC 2 ]

   Jaringan : 192.168.10.0/24
   DNS      : 192.168.10.2

Pada topologi ini, server Debian menjalankan layanan DNS. PC 1 dan PC 2 dikonfigurasi untuk menggunakan alamat DNS server tersebut.

Pastikan alamat IP server sudah statis dan klien dapat menjangkau server. DNS lokal hanya dapat digunakan oleh klien yang dapat mengakses server tersebut, kecuali DNS dikonfigurasi agar dapat diakses dari jaringan lain.
06 • PRAKTIK LINUX

Konfigurasi DNS Server Debian

Kita akan membuat DNS lokal menggunakan BIND9. Contoh domain yang digunakan adalah sekolah.test dengan alamat IP server 192.168.10.2.

Contoh ini menggunakan jaringan laboratorium. Domain sekolah.test ditujukan untuk penggunaan pengujian lokal, bukan domain website publik.

Langkah 1 — Periksa alamat IP

TERMINAL
ip -br a

Pastikan server memiliki alamat IP statis 192.168.10.2/24 pada interface jaringan yang benar. Nama interface setiap komputer bisa berbeda.

Langkah 2 — Instal BIND9

TERMINAL
sudo apt update
sudo apt install bind9 bind9-utils dnsutils

Langkah 3 — Daftarkan zona DNS

Buka file konfigurasi zona:

sudo nano /etc/bind/named.conf.local

Tambahkan konfigurasi berikut:

NAMED.CONF.LOCAL
zone "sekolah.test" {
    type master;
    file "/etc/bind/db.sekolah.test";
};

Langkah 4 — Buat file zona

TERMINAL
sudo cp /etc/bind/db.local /etc/bind/db.sekolah.test
sudo nano /etc/bind/db.sekolah.test

Ganti isi file dengan contoh berikut:

DB.SEKOLAH.TEST
$TTL 86400
@   IN  SOA ns1.sekolah.test. admin.sekolah.test. (
        2026101801
        3600
        1800
        604800
        86400
)
@       IN  NS  ns1.sekolah.test.
ns1     IN  A   192.168.10.2
@       IN  A   192.168.10.2
www     IN  A   192.168.10.2

Pada konfigurasi tersebut, domain utama dan subdomain www.sekolah.test diarahkan ke IP 192.168.10.2.

Langkah 5 — Periksa konfigurasi

TERMINAL
sudo named-checkconf
sudo named-checkzone sekolah.test /etc/bind/db.sekolah.test

Perintah pertama memeriksa konfigurasi utama BIND9. Perintah kedua memeriksa file zona. Pastikan tidak ada kesalahan sebelum melanjutkan.

Langkah 6 — Restart layanan

TERMINAL
sudo systemctl restart bind9
sudo systemctl status bind9

Langkah 7 — Uji DNS Server

TERMINAL
dig @192.168.10.2 sekolah.test
dig @192.168.10.2 www.sekolah.test
nslookup www.sekolah.test 192.168.10.2

Jika konfigurasi benar dan server dapat dijangkau, hasil pencarian seharusnya menunjukkan alamat 192.168.10.2.

Jika ingin mengakses website menggunakan domain tersebut, server juga harus menjalankan web server dan klien harus menggunakan DNS lokal ini. DNS hanya menerjemahkan nama ke alamat IP; DNS tidak membuat website.
07 • DHCP DAN DNS

Hubungan DHCP Server dengan DNS Server

DHCP dan DNS memiliki fungsi berbeda, tetapi keduanya dapat bekerja bersama dalam jaringan.

Layanan Fungsi
DHCP Server Memberikan IP, subnet mask, gateway, dan alamat DNS kepada klien.
DNS Server Menerjemahkan nama domain menjadi alamat IP.

Contohnya, DHCP dapat mengirimkan alamat DNS 192.168.10.2 kepada PC. Selanjutnya, PC menggunakan DNS tersebut untuk mencari alamat IP domain lokal.

08 • TROUBLESHOOTING

Masalah DNS yang Sering Terjadi

Masalah Yang Perlu Diperiksa
Domain tidak ditemukan Record DNS, nama domain, dan file zona.
Layanan gagal berjalan Konfigurasi BIND9 dan log layanan.
Klien tidak bisa mencari domain Alamat DNS klien, koneksi jaringan, dan firewall.
IP ditemukan tetapi website gagal dibuka Web server, port layanan, dan konfigurasi website.
Perubahan record belum terlihat TTL dan cache DNS pada klien atau resolver.

Perintah pemeriksaan

sudo systemctl status bind9
sudo journalctl -u bind9 --no-pager -n 50
sudo named-checkconf
dig @192.168.10.2 www.sekolah.test
09 • UJI PEMAHAMAN

Kuis DNS Server

Kesimpulan

DNS Server membantu menerjemahkan nama domain menjadi alamat IP. Pada Debian, BIND9 dapat digunakan untuk membuat DNS lokal dengan mengatur zona dan record. Agar klien dapat menggunakannya, pastikan alamat DNS klien benar, server dapat dijangkau, dan konfigurasi DNS telah diperiksa.
