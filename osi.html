MATERI 03 • NETWORKING

OSI Layer

Pelajari tujuh lapisan model OSI, fungsi setiap layer, contoh protokol, dan proses komunikasi data dalam jaringan komputer.

📚 7 Layer 🌐 Networking 🚀 Pemula 📝 5 Soal
01 — PENGERTIAN

Apa Itu OSI Layer?

OSI (Open Systems Interconnection) adalah model referensi yang membagi proses komunikasi jaringan menjadi tujuh lapisan. Setiap lapisan memiliki fungsi yang berbeda dan bekerja sama untuk membantu perangkat berkomunikasi.

Model OSI membantu kita memahami proses pengiriman data, mempelajari protokol jaringan, dan menganalisis masalah koneksi secara bertahap.

💡 Contoh: ketika membuka sebuah situs web, data melewati beberapa fungsi jaringan dari aplikasi hingga media pengiriman, kemudian diproses kembali di perangkat tujuan.
02 — TUJUH LAPISAN

Mengenal 7 OSI Layer

Urutan dari lapisan paling atas menuju lapisan paling bawah:

7

Application Layer

Menyediakan layanan jaringan yang digunakan aplikasi.

Contoh: HTTP, DNS, SMTP
6

Presentation Layer

Mengatur representasi data, seperti format, enkripsi, dan kompresi.

Contoh fungsi: encoding, enkripsi
5

Session Layer

Mengelola pembentukan, pemeliharaan, dan pengakhiran sesi komunikasi.

Fokus: sesi komunikasi
4

Transport Layer

Mendukung komunikasi antaraplikasi dan pengiriman data dari ujung ke ujung.

Contoh: TCP, UDP
3

Network Layer

Mengatur pengalamatan logis dan pemilihan rute paket.

Contoh: IP, router
2

Data Link Layer

Mengatur pengiriman frame pada satu link jaringan dan penggunaan alamat MAC.

Contoh: Ethernet, switch
1

Physical Layer

Mengirimkan bit melalui media fisik atau sinyal.

Contoh: kabel, konektor, sinyal
03 — FUNGSI LAYER

Bagaimana Setiap Layer Bekerja?

Layer 7–5: Lapisan Atas

Application, Presentation, dan Session berkaitan dengan layanan aplikasi, representasi data, serta pengelolaan sesi komunikasi. Ketiganya membantu aplikasi menggunakan layanan jaringan.

Layer 4: Transport

Lapisan ini mendukung komunikasi antaraplikasi. TCP menyediakan pengiriman yang andal, sedangkan UDP menawarkan pengiriman tanpa mekanisme keandalan dan koneksi yang sama seperti TCP.

Layer 3: Network

Lapisan ini menangani alamat IP dan pemilihan rute paket untuk mencapai jaringan tujuan.

Layer 2: Data Link

Lapisan ini menangani frame dan alamat MAC pada link jaringan. Switch Ethernet umumnya meneruskan frame berdasarkan alamat MAC.

Layer 1: Physical

Lapisan ini berkaitan dengan pengiriman bit melalui media fisik, seperti kabel tembaga, serat optik, atau sinyal radio.

04 — PROSES KOMUNIKASI

Bagaimana Data Dikirim?

Saat perangkat mengirimkan data, informasi diproses melalui fungsi lapisan komunikasi. Dalam penjelasan model OSI, proses pada sisi pengirim bergerak dari lapisan atas menuju lapisan bawah.

Pada sisi penerima, data diproses kembali dari lapisan bawah menuju lapisan atas agar dapat digunakan oleh aplikasi tujuan.

📌 Ingat: OSI adalah model referensi. Implementasi jaringan nyata, termasuk TCP/IP, tidak selalu memisahkan semua fungsi menjadi tujuh lapisan yang persis sama.

🎯 Tips Belajar

Hafalkan urutan layer dari 1 sampai 7, lalu pahami fungsi setiap layer dan contoh protokol yang berkaitan.

🧠 Cara Mengingat

Urutan dari bawah: Physical, Data Link, Network, Transport, Session, Presentation, Application.

💡

Tips Memahami OSI Layer

Jangan hanya menghafal nama layer. Pahami fungsi masing-masing, seperti IP pada Network, TCP/UDP pada Transport, dan alamat MAC pada Data Link.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ OSI memiliki tujuh lapisan.
✓ Application menyediakan layanan untuk aplikasi.
✓ Presentation menangani representasi data.
✓ Session mengelola sesi komunikasi.
✓ Transport berkaitan dengan komunikasi antaraplikasi.
✓ Network menangani IP dan rute paket.
✓ Data Link berkaitan dengan frame dan alamat MAC.
✓ Physical menangani pengiriman bit melalui media fisik.
