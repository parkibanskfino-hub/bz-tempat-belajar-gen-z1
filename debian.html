Debian

Pelajari pengertian Debian, karakteristik, kelebihan, struktur sistem, manajemen paket, perintah dasar, serta penggunaan Debian sebagai sistem operasi desktop maupun server.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

  • Menjelaskan pengertian Debian.
  • Mengetahui karakteristik Debian.
  • Memahami sistem manajemen paket Debian.
  • Mengenal perintah dasar Debian.
  • Mengetahui penggunaan Debian sebagai sistem desktop dan server.
01 — PENGENALAN

Apa Itu Debian?

Debian adalah distribusi sistem operasi berbasis Linux yang dikembangkan oleh komunitas melalui Debian Project.

Debian dikenal sebagai salah satu distribusi Linux yang memiliki banyak paket perangkat lunak, komunitas yang besar, serta dapat digunakan untuk berbagai kebutuhan mulai dari komputer desktop hingga server.

🔓

Open Source

Debian dikembangkan menggunakan banyak perangkat lunak open source dengan lisensi masing-masing.

📦

Banyak Paket

Debian menyediakan repositori dengan banyak paket perangkat lunak yang dapat dipasang melalui package manager.

🖥️

Desktop & Server

Debian dapat digunakan untuk kebutuhan desktop maupun sebagai sistem operasi server.

02 — KARAKTERISTIK

Karakteristik Debian

Debian memiliki beberapa karakteristik yang membuatnya banyak digunakan dalam berbagai lingkungan komputer.

🛡️

Stabil

Rilis stabil Debian berfokus pada kestabilan dan pengujian paket sebelum digunakan pada sistem stabil.

👥

Komunitas

Debian dikembangkan oleh komunitas pengembang dan kontributor dari berbagai tempat.

📦

Package Management

Debian menggunakan sistem paket yang memudahkan proses instalasi, pembaruan, dan penghapusan software.

⚙️

Fleksibel

Debian dapat dikonfigurasi untuk berbagai kebutuhan, termasuk desktop dan server.

03 — CABANG DEBIAN

Cabang Rilis Debian

Debian memiliki beberapa cabang pengembangan dengan tingkat kestabilan dan tujuan yang berbeda.

🟢

Stable

Cabang utama yang ditujukan untuk penggunaan yang membutuhkan kestabilan.

🟡

Testing

Berisi paket yang sedang dipersiapkan untuk menjadi bagian dari rilis stable berikutnya.

🔴

Unstable

Cabang pengembangan yang menerima perubahan dan paket baru lebih cepat.

🧪

Experimental

Area untuk paket atau perubahan yang masih dalam tahap eksperimen.

04 — PACKAGE MANAGEMENT

Manajemen Paket Debian

Salah satu hal penting yang perlu dipahami saat menggunakan Debian adalah pengelolaan paket perangkat lunak.

1

APT

APT adalah kumpulan tools yang digunakan untuk mengelola paket perangkat lunak dari repositori.

2

DPKG

dpkg merupakan sistem tingkat rendah yang digunakan untuk mengelola paket Debian dengan format .deb.

3

Repository

Repository merupakan tempat paket perangkat lunak disediakan agar dapat diakses oleh sistem.

4

Paket .deb

Paket dengan format .deb merupakan salah satu format paket perangkat lunak yang digunakan Debian.

05 — PERINTAH DASAR

Perintah Dasar Debian

Berikut beberapa perintah yang dapat digunakan untuk belajar administrasi Debian.

Contoh perintah:

Melihat isi direktori ls
Berpindah direktori cd
Mengetahui lokasi pwd
Memperbarui daftar paket apt update
Memasang paket apt install
Menghapus paket apt remove
Mencari paket apt search
Melihat informasi paket apt show
06 — STRUKTUR DIREKTORI

Direktori Penting di Debian

Linux menggunakan struktur direktori yang berbeda dengan sistem operasi Windows.

/

Root Directory

Direktori paling atas dalam struktur file system Linux.

1

/home

Menyimpan direktori dan file milik pengguna biasa.

2

/etc

Berisi berbagai file konfigurasi sistem dan layanan.

3

/var

Menyimpan data yang sering berubah, seperti beberapa file log dan data layanan.

4

/tmp

Digunakan untuk menyimpan file sementara.

07 — INSTALASI

Gambaran Instalasi Debian

Saat melakukan instalasi Debian, pengguna akan melewati beberapa tahapan konfigurasi.

1

Menyiapkan Media Instalasi

Siapkan media instalasi Debian dan pastikan perangkat memenuhi kebutuhan sistem.

2

Memilih Bahasa dan Lokasi

Installer akan meminta beberapa konfigurasi dasar seperti bahasa, lokasi, dan keyboard.

3

Konfigurasi Jaringan

Sistem dapat dikonfigurasi agar terhubung ke jaringan sesuai kebutuhan.

4

Membuat User

Pengguna dapat membuat akun dan mengatur informasi autentikasi sesuai konfigurasi instalasi.

5

Memilih Software

Installer dapat digunakan untuk memilih lingkungan desktop atau software sesuai kebutuhan.

6

Menyelesaikan Instalasi

Setelah konfigurasi selesai, sistem dipasang dan perangkat dapat melakukan boot ke Debian.

08 — KELEBIHAN

Kelebihan dan Tantangan Debian

✓ Kelebihan

  • Stabil dan cocok untuk berbagai kebutuhan.
  • Memiliki banyak paket perangkat lunak.
  • Dapat digunakan untuk desktop dan server.
  • Komunitas dan dokumentasi yang luas.
  • Sistem manajemen paket yang kuat.

📚 Yang Perlu Dipelajari

  • Penggunaan terminal.
  • Struktur direktori Linux.
  • Manajemen paket.
  • Permission dan user.
  • Konfigurasi jaringan dan service.
💡

Tips Belajar Debian

Kalau kamu baru belajar Debian, mulai dari mengenal desktop dan terminal. Setelah itu pelajari struktur direktori, perintah dasar, APT, user dan permission. Untuk latihan administrasi server, Debian juga dapat dipelajari menggunakan virtual machine.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ Debian adalah distribusi sistem operasi berbasis Linux.
✓ Debian dapat digunakan untuk komputer desktop maupun server.
✓ APT digunakan untuk membantu mengelola paket perangkat lunak.
✓ dpkg merupakan sistem tingkat rendah untuk mengelola paket Debian.
✓ Struktur direktori Linux menggunakan root "/" sebagai direktori paling atas.
✓ Menguasai terminal merupakan salah satu dasar penting untuk belajar Debian.
