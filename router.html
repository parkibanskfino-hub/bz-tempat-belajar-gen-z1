MATERI • NETWORKING

Mengenal Router

Pelajari bagaimana router menghubungkan jaringan yang berbeda, memilih jalur paket, dan menjadi penghubung jaringan lokal ke Internet.

Layer 3IP AddressRouting
01 • Pengertian

Apa Itu Router?

Router adalah perangkat jaringan yang menghubungkan dua atau lebih jaringan IP dan meneruskan paket berdasarkan alamat IP tujuan serta tabel routing. Router dapat menghubungkan LAN dengan Internet atau menghubungkan beberapa subnet.

Contoh: Komputer menggunakan jaringan Wi-Fi rumah, lalu router meneruskan lalu lintas menuju Internet melalui koneksi dari penyedia layanan Internet (ISP).
Menghubungkan jaringan

Meneruskan paket antarjaringan atau subnet yang berbeda.

Memilih rute

Melihat tabel routing untuk menentukan jalur paket.

Gateway

Sering menjadi default gateway perangkat dalam LAN.

Fitur tambahan

Router rumahan dapat menyediakan NAT, DHCP, firewall, dan Wi-Fi jika fiturnya tersedia.

02 • Cara Kerja

Bagaimana Router Bekerja?

  1. Paket dibuat.
    Komputer mengirim paket IP menuju alamat tujuan.
  2. Tujuan diperiksa.
    Router membaca alamat IP tujuan pada paket.
  3. Tabel routing dicari.
    Router memilih rute yang paling spesifik dan sesuai.
  4. Next hop atau antarmuka dipilih.
    Router menentukan ke mana paket harus diteruskan.
  5. Paket diteruskan.
    Router mengirim paket melalui antarmuka keluar yang dipilih, jika tersedia rute dan tidak ada aturan yang menghalangi.
Router tidak selalu mengetahui seluruh jalur Internet. Router menggunakan informasi pada tabel routing, yang dapat berasal dari konfigurasi statis atau protokol routing.

04 • Jenis Routing

Routing Statis dan Dinamis

Static Routing

Rute dimasukkan administrator secara manual. Cocok untuk jaringan kecil atau jalur yang sederhana.

Dynamic Routing

Router bertukar informasi rute menggunakan protokol seperti OSPF, RIP, atau BGP sesuai kebutuhan jaringan.

Default Route

Rute pilihan saat tidak ada rute yang lebih spesifik. Pada IPv4 sering ditulis 0.0.0.0/0.

Routing Table

Daftar rute yang digunakan router untuk memilih tujuan penerusan paket.

06 • Konfigurasi Dasar

Contoh Konfigurasi Router Cisco

Contoh berikut memberi alamat IP pada dua antarmuka router. Nama antarmuka dan alamat harus disesuaikan dengan topologi yang digunakan.

enable configure terminal interface gigabitEthernet 0/0 ip address 192.168.10.1 255.255.255.0 no shutdown exit interface gigabitEthernet 0/1 ip address 192.168.20.1 255.255.255.0 no shutdown exit end show ip interface brief show ip route

Jika kedua antarmuka aktif dan subnet dikonfigurasi dengan benar, router dapat melakukan routing di antara kedua jaringan yang terhubung langsung. PC juga harus menggunakan gateway yang sesuai.

Contoh gateway:
PC di jaringan 192.168.10.0/24 menggunakan gateway 192.168.10.1. PC di jaringan 192.168.20.0/24 menggunakan gateway 192.168.20.1.
07 • Contoh Topologi

Router Menghubungkan Dua LAN

PC A ── Switch A ── G0/0 [Router] G0/1 ── Switch B ── PC B 192.168.10.0/24 192.168.20.0/24 Gateway: 192.168.10.1 Gateway: 192.168.20.1

PC A dan PC B berada di subnet berbeda. Agar dapat berkomunikasi, masing-masing PC membutuhkan IP dan subnet mask yang benar, default gateway yang sesuai, serta tidak boleh ada aturan firewall yang menghalangi komunikasi tersebut.

08 • Kuis

Uji Pemahaman Router

Pilih satu jawaban yang benar.

1. Fungsi utama router adalah ...

Router menghubungkan jaringan dan meneruskan paket berdasarkan tabel routing.

2. Router umumnya dikaitkan dengan lapisan OSI ...

Routing IP merupakan fungsi Layer 3 atau Network.

3. Apa fungsi default gateway pada PC?

Default gateway biasanya merupakan router yang dapat meneruskan trafik ke jaringan lain.

4. Rute statis dikonfigurasi dengan cara ...

Static route dibuat secara manual.

5. Dua PC berbeda subnet ingin berkomunikasi. Apa yang umumnya diperlukan?

Komunikasi lintas subnet memerlukan perangkat Layer 3 dan konfigurasi jaringan yang benar.
09 • Ringkasan

Kesimpulan Router

  • Router menghubungkan jaringan IP yang berbeda.
  • Router memilih rute berdasarkan tabel routing.
  • Default gateway digunakan untuk mencapai jaringan di luar subnet lokal.
  • Routing dapat berupa statis atau dinamis.
  • NAT, DHCP, firewall, dan Wi-Fi adalah fitur tambahan yang bergantung pada perangkat.
