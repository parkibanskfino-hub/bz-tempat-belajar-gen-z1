Internet Protocol Version 4

Pelajari IPv4, struktur alamat 32 bit, cara membaca oktet biner, network ID, host ID, subnet mask, alamat private, dan contoh penerapannya pada jaringan.

🔢 32 Bit 🌐 Alamat IPv4 🧮 Subnet Mask 📝 5 Soal
01 — PENGERTIAN

Apa Itu IPv4?

IPv4 (Internet Protocol Version 4) adalah versi protokol internet yang menggunakan alamat sepanjang 32 bit untuk mengidentifikasi antarmuka perangkat dan membantu pengiriman paket data melalui jaringan IP.

Alamat IPv4 biasanya ditulis sebagai empat kelompok angka desimal yang dipisahkan oleh titik. Setiap kelompok disebut oktet dan memiliki nilai 0 sampai 255.

💡 Contoh alamat IPv4: 192.168.1.10. Alamat ini dapat digunakan sebagai alamat perangkat dalam jaringan lokal.
02 — STRUKTUR IPv4

Struktur Alamat IPv4

IPv4 terdiri dari 32 bit yang dibagi menjadi empat oktet. Setiap oktet memiliki panjang 8 bit.

192 . 168 . 1 . 10
Oktet 1 | Oktet 2 | Oktet 3 | Oktet 4
🔢

32 Bit

Total panjang alamat IPv4 adalah 32 bit.

🧩

4 Oktet

Setiap oktet memiliki panjang 8 bit.

📊

Desimal

Setiap oktet ditulis sebagai angka 0 sampai 255.

💻

Representasi Biner

Setiap oktet dapat direpresentasikan dengan delapan digit biner, yaitu 0 dan 1.

📌 IPv4 memiliki total 2³² kemungkinan pola alamat, tetapi tidak semuanya dapat digunakan sebagai alamat host biasa karena ada alamat khusus dan alamat yang dicadangkan.
03 — BILANGAN BINER

Mengenal Oktet Biner

Setiap oktet IPv4 terdiri dari delapan bit. Nilai setiap posisi bit, dari kiri ke kanan, adalah 128, 64, 32, 16, 8, 4, 2, dan 1.

Posisi Bit Nilai
Bit 1128
Bit 264
Bit 332
Bit 416
Bit 58
Bit 64
Bit 72
Bit 81

Contoh konversi

Angka desimal 192 dapat ditulis dalam biner sebagai 11000000 karena 128 + 64 = 192.

Desimal : 192
Biner : 11000000

Jadi, alamat IPv4 192.168.1.10 dapat direpresentasikan dalam bentuk biner sebagai empat oktet.

192 = 11000000
168 = 10101000
1 = 00000001
10 = 00001010
04 — NETWORK DAN HOST

Network ID dan Host ID

Pada alamat IPv4, bagian network menunjukkan jaringan tempat alamat berada, sedangkan bagian host mengidentifikasi antarmuka di dalam jaringan tersebut. Pembagian ini ditentukan oleh subnet mask atau prefix.

Contoh menggunakan /24

IP Address : 192.168.1.10
Prefix : /24
Subnet Mask: 255.255.255.0
Network : 192.168.1.0
Host : 10

Dengan prefix /24, 24 bit pertama merupakan bagian network dan 8 bit sisanya merupakan bagian host.

💡 Network ID dan host ID tidak selalu terbagi menjadi tiga oktet dan satu oktet. Pembagiannya bergantung pada prefix yang digunakan.
05 — SUBNET MASK

Subnet Mask dan Prefix

Subnet mask membantu menentukan bagian network dan host pada alamat IPv4. Prefix ditulis dengan tanda garis miring, misalnya /24.

Prefix Subnet Mask Jumlah Alamat
/8 255.0.0.0 16.777.216
/16 255.255.0.0 65.536
/24 255.255.255.0 256
/25 255.255.255.128 128
/26 255.255.255.192 64

Jumlah alamat pada tabel adalah jumlah seluruh alamat dalam subnet. Pada subnet IPv4 biasa, sebagian alamat digunakan untuk network dan broadcast sehingga tidak semuanya tersedia untuk host.

📌 Contoh: subnet /24 memiliki 256 alamat secara total dan biasanya menyediakan 254 alamat host.
06 — JENIS ALAMAT

IP Private dan IP Public

IP Private

Alamat private digunakan di jaringan lokal, seperti rumah, sekolah, dan laboratorium komputer.

Rentang Private Prefix
10.0.0.0 – 10.255.255.255 10.0.0.0/8
172.16.0.0 – 172.31.255.255 172.16.0.0/12
192.168.0.0 – 192.168.255.255 192.168.0.0/16

IP Public

IP public dapat dirutekan pada internet publik dan biasanya dialokasikan melalui penyedia layanan internet atau pengelola alamat IP.

⚠️ IP private tidak dapat diakses langsung melalui internet publik tanpa mekanisme jaringan tambahan, seperti NAT atau VPN sesuai konfigurasi.
07 — JENIS ALAMAT KHUSUS

Alamat IPv4 yang Perlu Dikenal

Alamat Fungsi
127.0.0.1 Alamat loopback untuk menguji sistem lokal.
0.0.0.0 Alamat khusus yang maknanya bergantung pada konteks.
255.255.255.255 Alamat broadcast terbatas pada IPv4.
169.254.0.0/16 Rentang link-local IPv4 yang dapat digunakan otomatis dalam kondisi tertentu.
💡 Jika komputer mendapatkan alamat 169.254.x.x, periksa konfigurasi jaringan dan layanan DHCP apabila komputer seharusnya mendapatkan alamat secara otomatis.
08 — KONFIGURASI DAN PENGUJIAN

Cara Memeriksa IPv4

Windows

Buka Command Prompt, lalu ketik:

ipconfig

Untuk informasi lebih lengkap, gunakan:

ipconfig /all

Linux

Buka terminal dan jalankan:

ip addr

Menguji koneksi

Gunakan ping ke alamat gateway yang sesuai dengan konfigurasi jaringanmu.

ping 192.168.1.1
📌 Alamat 192.168.1.1 hanya contoh. Gunakan alamat gateway yang sebenarnya pada jaringanmu.

Hafalkan bahwa IPv4 memiliki 32 bit dan empat oktet. Berlatihlah mengubah angka desimal menjadi biner serta membaca subnet mask.

Tips Memahami IPv4

Latihlah konversi desimal ke biner, pahami fungsi subnet mask, dan coba periksa alamat IPv4 pada komputer agar konsepnya lebih mudah dipahami.
