MATERI 01 • NETWORKING

Pengenalan Jaringan

Pelajari pengertian jaringan komputer, manfaat, jenis jaringan, perangkat jaringan, dan konsep dasar komunikasi data.

📘 Materi Dasar 🌐 Networking 🚀 Pemula 📝 5 Soal
01 — PENGERTIAN

Apa Itu Jaringan Komputer?

Jaringan komputer adalah hubungan antara dua atau lebih perangkat yang saling terhubung agar dapat bertukar data dan berbagi sumber daya.

Perangkat tersebut dapat berupa komputer, laptop, server, printer, dan perangkat jaringan. Hubungan dapat menggunakan kabel maupun koneksi nirkabel.

💡 Contoh: komputer di laboratorium sekolah terhubung ke switch sehingga dapat berkomunikasi melalui jaringan lokal.
02 — MANFAAT

Manfaat Jaringan Komputer

  • Berbagi file dan data antarperangkat.
  • Berbagi perangkat seperti printer.
  • Memudahkan komunikasi dan kolaborasi.
  • Menggunakan koneksi internet melalui jaringan.
  • Mendukung layanan server dan aplikasi jaringan.
03 — JENIS JARINGAN

Jenis Jaringan Berdasarkan Jangkauan

LAN (Local Area Network)

Jaringan pada area terbatas, seperti rumah, sekolah, kantor, atau laboratorium komputer.

MAN (Metropolitan Area Network)

Jaringan yang mencakup area lebih luas, misalnya wilayah kota.

WAN (Wide Area Network)

Jaringan dengan cakupan luas yang dapat menghubungkan jaringan antarwilayah atau antarnegara.

📌 Ingat: LAN, MAN, dan WAN memiliki perbedaan utama pada cakupan wilayah jaringan.
04 — PERANGKAT JARINGAN

Perangkat yang Digunakan

1. NIC

Network Interface Card memungkinkan perangkat terhubung ke jaringan.

2. Switch

Menghubungkan beberapa perangkat dalam jaringan lokal.

3. Router

Meneruskan paket data antarjaringan yang berbeda.

4. Server

Menyediakan layanan atau sumber daya bagi perangkat klien, misalnya layanan file atau web.
