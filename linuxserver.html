Linux Server

Pelajari pengertian Linux Server, fungsi, layanan server, distribusi Linux Server, perintah dasar, serta konsep pengelolaan server.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

  • Menjelaskan pengertian Linux Server.
  • Mengetahui fungsi server.
  • Mengenal layanan yang dapat dijalankan pada Linux Server.
  • Mengenal distribusi Linux yang digunakan untuk server.
  • Memahami perintah dasar administrasi server.
01 — PENGENALAN

Apa Itu Linux Server?

Linux Server adalah sistem server yang menggunakan Linux sebagai sistem operasinya untuk menyediakan layanan kepada komputer atau perangkat lain melalui jaringan.

Server biasanya bekerja untuk menerima permintaan dari client kemudian memberikan layanan atau sumber daya yang dibutuhkan. Linux banyak digunakan sebagai server karena fleksibel dan memiliki banyak tools untuk administrasi sistem.

🌐

Melayani Client

Server menyediakan layanan yang dapat digunakan oleh komputer atau perangkat lain melalui jaringan.

⚙️

Administrasi

Administrator dapat mengatur pengguna, layanan, jaringan, penyimpanan, dan konfigurasi sistem.

🛡️

Keamanan

Linux menyediakan mekanisme pengguna, permission, firewall, dan berbagai tools keamanan.

02 — FUNGSI SERVER

Fungsi Linux Server

Linux Server dapat digunakan untuk berbagai kebutuhan jaringan dan teknologi informasi.

🌐

Web Server

Digunakan untuk menyediakan halaman atau aplikasi web kepada client melalui jaringan.

📁

File Server

Digunakan untuk menyediakan penyimpanan dan berbagi file melalui jaringan.

🗄️

Database Server

Menyediakan layanan untuk menyimpan, mengelola, dan melayani permintaan data.

📡

DNS Server

Membantu menerjemahkan nama domain atau hostname menjadi alamat IP.

📬

Mail Server

Dapat digunakan untuk menyediakan layanan pengiriman dan penerimaan email.

🔐

SSH Server

Menyediakan akses administrasi jarak jauh melalui koneksi yang terenkripsi.

03 — DISTRIBUSI

Distribusi Linux untuk Server

Linux memiliki berbagai distribusi yang dapat digunakan untuk kebutuhan server.

Debian

Dikenal sebagai distribusi yang stabil dan memiliki banyak paket perangkat lunak.

Ubuntu Server

Distribusi server yang populer dan memiliki dokumentasi serta komunitas yang luas.

Rocky Linux

Distribusi yang ditujukan untuk lingkungan server dan kompatibilitas dengan ekosistem Enterprise Linux.

AlmaLinux

Distribusi Linux yang berfokus pada kebutuhan server dan lingkungan Enterprise Linux.

Fedora Server

Edisi Fedora yang ditujukan untuk kebutuhan server dan pengembangan.

openSUSE

Distribusi Linux yang menyediakan berbagai tools untuk administrasi sistem.

04 — KOMPONEN

Komponen Penting Linux Server

Administrator server perlu memahami beberapa bagian utama dari sistem Linux.

1

Kernel

Bagian inti Linux yang mengatur komunikasi antara hardware dan software serta sumber daya sistem.

2

Shell

Digunakan untuk memberikan perintah kepada sistem melalui terminal.

3

User dan Group

Digunakan untuk mengatur identitas pengguna serta hak akses pada sistem.

4

File System

Digunakan untuk menyimpan dan mengorganisasi file serta direktori.

5

Service

Program yang berjalan di background untuk menyediakan fungsi tertentu kepada sistem atau client.

05 — TERMINAL

Perintah Dasar Linux Server

Administrator Linux Server sering menggunakan terminal untuk melakukan konfigurasi dan pemeriksaan sistem.

Contoh perintah yang perlu dipelajari:

Melihat isi direktori ls
Mengetahui lokasi direktori pwd
Berpindah direktori cd
Melihat informasi sistem uname
Melihat penggunaan disk df
Melihat proses ps
Mengubah permission chmod
Mengubah pemilik file chown
06 — CARA KERJA

Cara Kerja Linux Server

Secara sederhana, komunikasi antara client dengan server dapat berlangsung seperti berikut.

1

Client Mengirim Request

Komputer atau perangkat client mengirimkan permintaan melalui jaringan.

2

Server Menerima Request

Layanan yang berjalan pada Linux Server menerima permintaan tersebut.

3

Server Memproses Request

Server memproses permintaan dan mengambil atau mengolah data yang diperlukan.

4

Server Mengirim Response

Hasil pemrosesan dikirim kembali kepada client melalui jaringan.

07 — KELEBIHAN

Kelebihan Linux Server

✓ Kelebihan

  • Fleksibel untuk berbagai kebutuhan server.
  • Banyak tools administrasi tersedia.
  • Mendukung berbagai layanan jaringan.
  • Banyak digunakan pada lingkungan server dan cloud.
  • Memiliki komunitas dan dokumentasi yang luas.

📚 Hal yang Perlu Dipelajari

  • Dasar jaringan komputer.
  • Command Line Interface.
  • Permission dan user.
  • Konfigurasi layanan server.
  • Keamanan dan backup data.
💡

Tips Belajar Linux Server

Kalau baru mulai belajar server, pahami terlebih dahulu dasar Linux dan jaringan. Setelah itu kamu bisa belajar membuat server sederhana menggunakan virtual machine, kemudian mencoba layanan seperti SSH, web server, DNS, dan file server.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ Linux Server digunakan untuk menyediakan layanan kepada client melalui jaringan.
✓ Linux Server dapat digunakan sebagai web server, file server, DNS, database, mail server, dan SSH server.
✓ Debian dan Ubuntu Server merupakan contoh distribusi yang dapat digunakan sebagai server.
✓ Administrator dapat mengelola server menggunakan terminal.
✓ User, permission, service, dan jaringan merupakan bagian penting dalam administrasi server.
✓ Dasar Linux dan jaringan merupakan fondasi penting sebelum mempelajari administrasi server.
