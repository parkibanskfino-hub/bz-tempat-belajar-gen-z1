FTP Server

Pelajari fungsi FTP Server, transfer file, dan praktik layanan FTP menggunakan vsftpd di Debian.

File TransfervsftpdDebian Linux
01 • PENGENALAN

Apa Itu FTP Server?

FTP (File Transfer Protocol) adalah protokol jaringan untuk mentransfer file antara klien dan server. FTP biasa tidak mengenkripsi kredensial atau data; untuk transfer aman, pertimbangkan SFTP atau FTPS.

📤 UploadMengirim file ke server.
📥 DownloadMengambil file dari server.
👤 UserAkun yang diberi hak akses.
🔐 PermissionMengatur izin file dan folder.
02 • FUNGSI

Fungsi FTP Server

  • Memindahkan file antara komputer dan server.
  • Mengunggah dan mengunduh file.
  • Mengelola file dalam jaringan.
  • Mengatur akses berdasarkan akun dan izin direktori.
Keamanan: Hindari FTP biasa untuk akun sensitif di internet karena kata sandi dan data dapat terbaca saat transit.
03 • CARA KERJA

Alur Transfer File

1
Klien terhubung

Klien menghubungi alamat FTP server.

2
Autentikasi

Server memeriksa akun jika autentikasi digunakan.

3
Permintaan transfer

Klien meminta daftar file, upload, atau download.

4
Server memeriksa izin

Transfer dilakukan jika akses diizinkan.

FTP biasanya memakai port 21 untuk kontrol. Port data bergantung pada mode aktif/pasif dan konfigurasi.
04 • PRAKTIK DEBIAN

Instal FTP Server vsftpd

1. Instal layanan

sudo apt update
sudo apt install vsftpd

2. Cadangkan dan edit konfigurasi

sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.bak
sudo nano /etc/vsftpd.conf

Periksa opsi dasar berikut; sesuaikan dengan konfigurasi default versi Debian yang terpasang:

anonymous_enable=NO
local_enable=YES
write_enable=YES
local_umask=022

3. Buat akun khusus

sudo adduser ftpuser

Gunakan kata sandi kuat dan akun khusus untuk latihan, bukan akun administrator.

4. Aktifkan layanan

sudo systemctl enable --now vsftpd
sudo systemctl restart vsftpd
sudo systemctl status vsftpd

5. Uji koneksi

Gunakan klien FTP di jaringan laboratorium untuk mengakses IP server dengan akun yang dibuat.

Jangan mengaktifkan anonymous write access. Untuk transfer terenkripsi, gunakan SFTP atau konfigurasi FTPS yang benar. Mode pasif mungkin memerlukan rentang port khusus di firewall.
