Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

01 — PENGENALAN

Apa Itu Linux?

Linux adalah keluarga sistem operasi berbasis kernel Linux yang banyak digunakan pada komputer, server, perangkat jaringan, dan berbagai perangkat lainnya.

Linux dikenal luas karena ekosistemnya yang terbuka. Banyak distribusi Linux dikembangkan menggunakan perangkat lunak open source sehingga pengguna dan pengembang dapat mempelajari, menyesuaikan, dan mengembangkan sistem sesuai kebutuhan dan lisensi yang berlaku.

🔓

Open Source

Banyak komponen Linux tersedia sebagai perangkat lunak open source sehingga kode sumbernya dapat dipelajari sesuai lisensinya.

🛡️

Stabil

Linux banyak digunakan pada server dan sistem yang membutuhkan kestabilan.

⚙️

Fleksibel

Linux tersedia dalam berbagai distribusi dengan pilihan lingkungan desktop dan konfigurasi yang beragam.

02 — DISTRIBUSI

Distribusi Linux

Linux tersedia dalam banyak distribusi atau distro. Setiap distro memiliki tujuan dan karakteristik yang berbeda.

🟠

Ubuntu

Salah satu distro Linux yang populer dan sering digunakan untuk desktop, pembelajaran, serta server.

🔴

Debian

Distribusi Linux yang dikenal memiliki komunitas besar dan menjadi dasar bagi beberapa distribusi lainnya.

🔵

Fedora

Distribusi yang dikembangkan dalam ekosistem Fedora dan sering digunakan untuk desktop serta pengembangan.

🟢

Linux Mint

Distro yang berfokus pada kemudahan penggunaan desktop dan cocok untuk pengguna yang baru mengenal Linux.

03 — FUNGSI

Fungsi Linux

Linux dapat digunakan untuk berbagai kebutuhan komputasi.

🖥️

Desktop

Digunakan sebagai sistem operasi pada komputer dan laptop untuk aktivitas sehari-hari.

🖧

Server

Banyak digunakan untuk menyediakan berbagai layanan jaringan dan server.

🌐

Jaringan

Dapat digunakan untuk berbagai kebutuhan administrasi dan pengelolaan jaringan.

👨‍💻

Pemrograman

Menyediakan berbagai tools yang sering digunakan dalam pengembangan perangkat lunak.

☁️

Cloud

Linux banyak digunakan sebagai bagian dari infrastruktur server dan cloud.

📡

Perangkat Khusus

Linux juga dapat digunakan pada berbagai perangkat dan sistem dengan kebutuhan khusus.

04 — STRUKTUR

Komponen Dasar Linux

Sistem Linux terdiri dari beberapa bagian yang bekerja bersama.

1

Kernel

Inti sistem yang berfungsi mengatur komunikasi antara perangkat keras dan perangkat lunak.

2

Shell

Antarmuka yang memungkinkan pengguna memberikan perintah kepada sistem melalui terminal.

3

File System

Sistem yang digunakan untuk mengatur file dan direktori pada penyimpanan.

4

User Interface

Linux dapat menggunakan antarmuka grafis atau terminal sesuai kebutuhan pengguna.

05 — TERMINAL

Perintah Dasar Linux

Terminal merupakan salah satu cara penting untuk berinteraksi dengan sistem Linux. Berikut beberapa perintah dasar yang umum dipelajari.

Contoh perintah dasar Linux:

Melihat isi folder ls
Berpindah direktori cd
Mengetahui lokasi pwd
Membuat folder mkdir
Membuat file kosong touch
Menyalin file cp
Memindahkan file mv
Menghapus file rm
06 — CARA KERJA

Cara Linux Menjalankan Program

Saat pengguna menjalankan sebuah program, Linux mengelola berbagai sumber daya agar program dapat bekerja.

1

Pengguna Memberikan Perintah

Pengguna menjalankan aplikasi melalui desktop atau terminal.

2

Shell atau Sistem Menerima Perintah

Perintah diteruskan ke sistem untuk diproses.

3

Kernel Mengatur Sumber Daya

Kernel membantu mengatur processor, memori, penyimpanan, dan perangkat yang dibutuhkan.

4

Program Berjalan

Program mendapatkan sumber daya yang diperlukan dan menjalankan tugasnya.

07 — KELEBIHAN

Kelebihan dan Hal yang Perlu Dipelajari

✓ Kelebihan

  • Banyak pilihan distribusi.
  • Banyak perangkat lunak open source.
  • Fleksibel untuk berbagai kebutuhan.
  • Banyak digunakan pada server.
  • Cocok untuk belajar administrasi sistem dan jaringan.

📚 Hal yang Perlu Dipelajari

  • Perintah terminal.
  • Struktur direktori Linux.
  • Hak akses file.
  • Instalasi dan pengelolaan paket.
  • Administrasi pengguna dan sistem.
💡

Tips Belajar Linux

Kalau kamu baru belajar Linux, mulai dari mengenal struktur folder, mencoba perintah terminal dasar, memahami permission, lalu lanjut ke instalasi software dan administrasi sistem. Kamu juga bisa mencoba Linux melalui virtual machine agar lebih aman untuk belajar.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ Linux merupakan keluarga sistem operasi berbasis kernel Linux.
✓ Linux memiliki banyak distribusi seperti Ubuntu, Debian, Fedora, dan Linux Mint.
✓ Linux banyak digunakan pada desktop, server, jaringan, dan cloud.
✓ Kernel merupakan bagian inti yang mengelola sumber daya sistem.
✓ Terminal dapat digunakan untuk menjalankan berbagai perintah.
✓ Linux cocok dipelajari untuk memahami sistem operasi dan administrasi komputer.
