BIOS

Pelajari pengertian BIOS, fungsi BIOS, pengaturan dasar, proses booting, serta cara mengenali menu BIOS pada komputer.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi BIOS, kamu diharapkan dapat:

  • Menjelaskan pengertian BIOS.
  • Mengetahui fungsi BIOS pada komputer.
  • Mengenali menu-menu dasar BIOS.
  • Memahami proses booting komputer.
  • Mengetahui pengaturan dasar BIOS.
01 — PENGENALAN

Apa Itu BIOS?

BIOS merupakan singkatan dari Basic Input/Output System. BIOS adalah firmware yang digunakan komputer untuk melakukan proses awal ketika komputer dinyalakan.

BIOS membantu melakukan pemeriksaan awal terhadap perangkat keras dan kemudian menjalankan proses untuk menemukan perangkat yang digunakan untuk melakukan booting.

⚡

Startup

BIOS bekerja ketika komputer mulai dinyalakan untuk memulai proses awal.

🔍

Pemeriksaan Hardware

BIOS melakukan pemeriksaan awal terhadap perangkat keras komputer.

💿

Booting

BIOS membantu menentukan perangkat yang digunakan untuk proses booting.

02 — FUNGSI BIOS

Fungsi Utama BIOS

BIOS memiliki beberapa fungsi penting sebelum sistem operasi mulai berjalan.

🔎 POST

Melakukan pemeriksaan awal terhadap komponen perangkat keras ketika komputer dinyalakan.

💻 Booting

Membantu proses awal untuk menemukan perangkat penyimpanan yang berisi sistem operasi.

⚙️ Konfigurasi Hardware

Menyediakan pengaturan dasar untuk berbagai perangkat keras komputer.

🔐 Keamanan

Pada sistem tertentu, firmware dapat menyediakan pengaturan keamanan seperti password firmware.

03 — POST

Apa Itu POST?

POST atau Power-On Self-Test adalah proses pemeriksaan awal yang dilakukan ketika komputer mulai menyala.

1

Komputer Dinyalakan

Ketika tombol power ditekan, sistem mulai melakukan proses inisialisasi.

2

Hardware Diperiksa

Firmware melakukan pemeriksaan awal terhadap komponen tertentu yang tersedia.

3

Proses Boot Berlanjut

Setelah proses awal selesai, komputer melanjutkan proses boot menuju sistem operasi.

04 — MENU BIOS

Pengaturan Dasar BIOS

Tampilan dan nama menu dapat berbeda tergantung motherboard atau firmware yang digunakan.

1

Boot Order

Mengatur urutan perangkat yang digunakan komputer ketika mencari media untuk melakukan booting.

2

System Information

Menampilkan informasi dasar seperti processor, memori, dan versi firmware.

3

Date & Time

Digunakan untuk mengatur tanggal dan waktu sistem.

4

Security

Pada perangkat tertentu terdapat pengaturan keamanan seperti password firmware.

5

Hardware Configuration

Menyediakan berbagai konfigurasi perangkat keras yang didukung sistem.

6

Save & Exit

Digunakan untuk menyimpan perubahan pengaturan atau keluar dari menu BIOS.

05 — AKSES BIOS

Cara Masuk ke BIOS

Tombol untuk membuka BIOS dapat berbeda tergantung produsen motherboard atau komputer. Tombol yang umum digunakan antara lain Delete, F2, F10, atau Esc.

1

Matikan atau Restart PC

Pastikan komputer melakukan proses restart atau mulai dinyalakan.

2

Perhatikan Layar Awal

Pada beberapa perangkat terdapat petunjuk tombol yang digunakan untuk masuk ke firmware setup.

3

Tekan Tombol yang Sesuai

Tekan tombol sesuai petunjuk perangkat, misalnya Delete atau F2.

⚠️

Hati-Hati Mengubah Pengaturan

Jangan mengubah pengaturan BIOS secara sembarangan. Beberapa pengaturan dapat memengaruhi proses booting atau cara perangkat keras bekerja. Jika belum memahami suatu opsi, sebaiknya periksa dokumentasi motherboard terlebih dahulu.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ BIOS adalah firmware yang bekerja pada tahap awal komputer dinyalakan.
✓ BIOS melakukan proses pemeriksaan awal terhadap hardware.
✓ BIOS berhubungan dengan proses booting.
✓ Boot Order menentukan urutan perangkat yang diperiksa untuk booting.
✓ Menu BIOS dapat berbeda pada setiap perangkat.
✓ Jangan mengubah pengaturan yang belum kamu pahami.
