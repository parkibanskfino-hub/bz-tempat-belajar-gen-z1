VirtualBox

Kenali teknologi virtualisasi, fungsi VirtualBox, komponen mesin virtual, serta langkah membuat komputer virtual untuk belajar Linux dan sistem operasi.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

  • Menjelaskan pengertian VirtualBox.
  • Memahami fungsi virtualisasi.
  • Mengenal komponen mesin virtual.
  • Memahami langkah membuat mesin virtual.
  • Mengenal pengaturan RAM, penyimpanan, dan jaringan.
01 — PENGENALAN

Apa Itu VirtualBox?

VirtualBox adalah perangkat lunak virtualisasi yang memungkinkan pengguna menjalankan sistem operasi lain di dalam komputer melalui sebuah mesin virtual atau Virtual Machine (VM).

Contohnya, jika komputer kamu menggunakan Windows, kamu dapat membuat mesin virtual untuk belajar Debian atau Linux tanpa harus mengganti sistem operasi utama. Sistem operasi di dalam VM disebut guest, sedangkan sistem operasi utama disebut host.

💻

Host OS

Sistem operasi utama yang terpasang pada komputer fisik.

🖥️

Guest OS

Sistem operasi yang dijalankan di dalam mesin virtual.

📦

Virtual Machine

Komputer virtual dengan perangkat keras yang disimulasikan oleh software.

02 — FUNGSI

Fungsi VirtualBox

VirtualBox berguna untuk kegiatan belajar, pengujian, dan pengembangan.

🐧

Belajar Linux

Mencoba Debian, Ubuntu, dan distribusi Linux lainnya.

🧪

Pengujian Software

Menguji aplikasi atau konfigurasi dalam lingkungan terpisah.

🌐

Simulasi Jaringan

Mempelajari komunikasi antar-VM dan layanan jaringan.

🎓

Praktik Sekolah

Berlatih instalasi sistem operasi tanpa perlu banyak komputer fisik.

📸

Snapshot

Menyimpan keadaan VM agar bisa dikembalikan ke kondisi sebelumnya.

🗂️

Lingkungan Terpisah

Menjalankan beberapa sistem operasi pada satu komputer, sesuai kemampuan perangkat.

03 — KOMPONEN

Komponen Penting VirtualBox

1

RAM

Memori yang dialokasikan untuk mesin virtual ketika berjalan. Alokasi harus menyisakan cukup RAM untuk host.

2

Virtual Hard Disk

Media penyimpanan virtual untuk sistem operasi, aplikasi, dan file guest.

3

ISO Image

File citra instalasi yang dapat digunakan sebagai media boot untuk memasang sistem operasi.

4

CPU

Jumlah inti prosesor yang dialokasikan kepada VM. Jangan mengalokasikan seluruh kemampuan CPU tanpa mempertimbangkan host.

5

Network Adapter

Pengaturan jaringan yang menentukan bagaimana VM terhubung ke host, VM lain, atau jaringan luar.

04 — PEMBUATAN VM

Cara Membuat Mesin Virtual

Berikut alur umum membuat VM untuk belajar Debian atau Linux.

1

Pasang VirtualBox

Unduh installer VirtualBox dari situs resmi Oracle, lalu pasang sesuai sistem operasi host.

2

Siapkan File ISO

Unduh ISO sistem operasi yang ingin dipelajari dari situs resmi distribusinya.

3

Buat Mesin Virtual

Klik tombol New, isi nama VM, lalu pilih file ISO dan jenis sistem operasi jika diperlukan.

4

Atur RAM dan CPU

Pilih alokasi sumber daya sesuai kemampuan komputer dan persyaratan sistem operasi guest.

5

Buat Virtual Hard Disk

Tentukan ukuran penyimpanan yang cukup untuk instalasi sistem operasi dan kebutuhan latihan.

6

Jalankan dan Instal

Mulai VM, ikuti petunjuk installer, kemudian lepaskan ISO jika diperlukan setelah instalasi selesai.

05 — MODE JARINGAN

Jenis Network Adapter

VirtualBox menyediakan beberapa mode jaringan. Pilih sesuai tujuan latihan.

🔗

NAT

VM biasanya dapat mengakses jaringan luar melalui koneksi host tanpa harus terlihat langsung di jaringan lokal.

🏠

Bridged Adapter

VM terhubung ke jaringan fisik seperti perangkat tersendiri, sesuai dukungan jaringan yang digunakan.

🔒

Host-Only

Membuat jaringan antara host dan VM untuk latihan komunikasi lokal tanpa akses luar secara langsung melalui adapter tersebut.

06 — PENGATURAN

Pengaturan yang Perlu Diketahui

1

System

Untuk mengatur RAM, urutan boot, dan beberapa konfigurasi prosesor VM.

2

Display

Untuk mengatur tampilan dan memori video virtual sesuai kebutuhan guest.

3

Storage

Untuk mengelola virtual hard disk dan media ISO yang digunakan VM.

4

Network

Untuk mengatur mode jaringan dan adapter yang digunakan VM.

5

Snapshots

Untuk menyimpan kondisi VM pada titik tertentu sebelum melakukan perubahan besar.

07 — KELEBIHAN DAN KETERBATASAN

Hal yang Perlu Diperhatikan

✅

Kelebihan

Memudahkan latihan banyak sistem operasi, pengujian, dan simulasi jaringan pada satu komputer.

⚠️

Keterbatasan

VM memakai sumber daya komputer. Performa dapat menurun jika RAM, CPU, atau penyimpanan tidak mencukupi.

🛡️

Keamanan

VM bukan jaminan isolasi mutlak. Gunakan ISO tepercaya, backup, dan pengaturan jaringan yang sesuai.

💡 Tips Belajar VirtualBox

Mulailah dengan membuat satu VM Debian. Pelajari cara memasang sistem operasi, menggunakan terminal, mengatur jaringan NAT, dan membuat snapshot sebelum mengubah konfigurasi. Pastikan spesifikasi komputer memenuhi kebutuhan sistem operasi yang akan dijalankan.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ VirtualBox merupakan perangkat lunak virtualisasi.
✓ VM memungkinkan sistem operasi guest berjalan di dalam host.
✓ ISO digunakan sebagai media instalasi sistem operasi.
✓ RAM, CPU, dan penyimpanan perlu dialokasikan dengan tepat.
✓ NAT, Bridged, dan Host-Only memiliki kegunaan jaringan berbeda.
✓ Snapshot membantu menyimpan kondisi VM sebelum perubahan.
