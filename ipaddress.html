Pengenalan IP Address

Pelajari pengertian alamat IP, fungsi IP address, IPv4 dan IPv6, kelas alamat IPv4, subnet mask, serta cara memeriksa alamat IP pada komputer.

🌐 IPv4 & IPv6 💻 Konfigurasi IP 🔢 Subnet Mask 📝 5 Soal
01 — PENGERTIAN

Apa Itu IP Address?

IP Address (Internet Protocol Address) adalah alamat logis yang diberikan pada antarmuka perangkat jaringan agar perangkat dapat dikenali dan berkomunikasi menggunakan protokol IP.

IP address digunakan pada perangkat seperti komputer, laptop, server, router, dan perangkat lain yang terhubung ke jaringan.

💡 Contoh: 192.168.1.10 merupakan contoh alamat IPv4 yang sering digunakan pada jaringan lokal.
02 — FUNGSI IP ADDRESS

Fungsi IP Address

🏷️

1. Identitas Perangkat

Membantu mengidentifikasi antarmuka perangkat dalam komunikasi jaringan.

📡

2. Mengirim Data

Membantu paket data dikirim menuju alamat tujuan melalui jaringan IP.

🔗

3. Komunikasi Jaringan

Memungkinkan perangkat berkomunikasi dengan perangkat lain sesuai konfigurasi jaringan.

🧭

4. Routing

Informasi alamat IP membantu router menentukan jalur pengiriman paket ke jaringan tujuan.

📌 IP address harus dikonfigurasi dengan benar. Alamat yang salah atau bertabrakan dapat menyebabkan masalah komunikasi jaringan.
03 — JENIS IP ADDRESS

Mengenal IPv4 dan IPv6

IPv4

IPv4 menggunakan alamat sepanjang 32 bit yang ditulis dalam empat kelompok angka desimal. Setiap kelompok memiliki nilai dari 0 sampai 255 dan dipisahkan dengan tanda titik.

192.168.1.10

IPv6

IPv6 menggunakan alamat sepanjang 128 bit yang ditulis dalam kelompok bilangan heksadesimal dan dipisahkan dengan tanda titik dua.

2001:db8::1
Perbedaan IPv4 IPv6
Panjang 32 bit 128 bit
Penulisan Desimal bertitik Heksadesimal bertitik dua
Contoh 192.168.1.10 2001:db8::1
💡 IPv6 menyediakan ruang alamat yang jauh lebih besar daripada IPv4.
04 — JENIS PENGALAMATAN

IP Private dan IP Public

IP Private

IP private digunakan di jaringan lokal, seperti rumah, sekolah, laboratorium komputer, dan kantor. Alamat ini tidak dirutekan secara langsung melalui internet publik.

Rentang IPv4 Private Subnet
10.0.0.0 – 10.255.255.255 10.0.0.0/8
172.16.0.0 – 172.31.255.255 172.16.0.0/12
192.168.0.0 – 192.168.255.255 192.168.0.0/16

IP Public

IP public merupakan alamat yang dapat dirutekan pada internet publik. Alamat ini biasanya dialokasikan oleh penyedia layanan internet atau pihak yang mengelola blok alamat IP.

📌 Contoh alamat private: 192.168.1.10. Alamat tersebut dapat digunakan di jaringan lokal selama tidak bertabrakan dengan perangkat lain dalam jaringan yang sama.
05 — KELAS IPv4

Pembagian Kelas IPv4

Secara historis, IPv4 dibagi menjadi kelas A, B, C, D, dan E. Pembagian kelas ini penting untuk dipahami sebagai dasar pembelajaran jaringan. Jaringan modern umumnya menggunakan CIDR untuk menentukan prefiks dan ukuran jaringan.

Kelas Rentang Oktet Pertama Penggunaan Umum
A 1–126 Historis, jaringan besar
B 128–191 Historis, jaringan menengah
C 192–223 Historis, jaringan kecil
D 224–239 Multicast
E 240–255 Dicadangkan untuk keperluan khusus
⚠️ Rentang kelas A, B, dan C di atas merupakan pembagian historis. Alamat 127.0.0.0/8 digunakan untuk loopback, sedangkan 0.0.0.0 memiliki fungsi khusus.
06 — SUBNET MASK

Apa Itu Subnet Mask?

Subnet mask digunakan pada IPv4 untuk membedakan bagian network dan bagian host dari suatu alamat IP. Informasi ini membantu perangkat menentukan apakah alamat tujuan berada di jaringan lokal atau perlu dijangkau melalui router.

Contoh konfigurasi

Pengaturan Nilai Contoh
IP Address 192.168.1.10
Subnet Mask 255.255.255.0
Prefix /24
Network Address 192.168.1.0
Broadcast Address 192.168.1.255
Rentang Host Umum 192.168.1.1–192.168.1.254
💡 Pada jaringan IPv4 biasa dengan prefix /24, terdapat 256 alamat dalam satu subnet, dengan 254 alamat host yang umumnya dapat digunakan.
07 — KONFIGURASI IP

Cara Melihat IP Address

Windows

Buka Command Prompt, lalu ketik perintah berikut.

ipconfig

Untuk menampilkan informasi jaringan yang lebih lengkap, gunakan:

ipconfig /all

Linux

Buka terminal dan jalankan:

ip addr

Menguji koneksi

Jika ingin menguji apakah gateway dapat dijangkau, gunakan perintah ping dengan alamat gateway jaringanmu.

ping 192.168.1.1
📌 Ganti alamat contoh dengan alamat gateway yang benar pada jaringan yang sedang digunakan.
