Mengenal Switch

Pelajari fungsi switch, cara kerja pengiriman data, MAC address, VLAN, jenis switch, dan penerapannya dalam jaringan komputer.

Layer 2MAC AddressVLAN
01 • Pengertian

Apa Itu Switch?

Switch adalah perangkat jaringan yang menghubungkan beberapa perangkat dalam jaringan lokal (LAN), seperti komputer, server, printer, dan access point. Switch meneruskan frame Ethernet menuju port yang sesuai berdasarkan MAC address tujuan.

Contoh: Beberapa komputer di laboratorium terhubung ke satu switch sehingga dapat berkomunikasi dalam jaringan lokal.
Menghubungkan perangkat

Menghubungkan komputer, server, printer, dan perangkat jaringan melalui kabel.

Meneruskan frame

Mengirim frame ke port tujuan berdasarkan MAC address yang dipelajari.

Mendukung VLAN

Switch terkelola dapat memisahkan jaringan logis menjadi beberapa VLAN.

Menambah port LAN

Memungkinkan lebih banyak perangkat terhubung melalui Ethernet.

02 • Cara Kerja

Bagaimana Switch Bekerja?

Switch Ethernet umumnya bekerja pada Layer 2 (Data Link) model OSI. Switch mempelajari MAC address sumber dari frame yang diterima dan mencatat port tempat perangkat tersebut berada.

  1. Frame diterima.
    Komputer mengirim data ke switch melalui kabel jaringan.
  2. MAC address sumber dipelajari.
    Switch mencatat MAC address sumber dan port masuknya pada tabel MAC address.
  3. MAC tujuan diperiksa.
    Switch mencari MAC address tujuan di tabelnya.
  4. Frame diteruskan.
    Jika tujuan diketahui, frame dikirim ke port tujuan yang sesuai, bukan ke semua port.
  5. Flooding bila tujuan belum diketahui.
    Frame unicast yang tujuannya belum dikenal dapat diteruskan ke port lain dalam VLAN yang sama, kecuali port masuk.
Switch tidak selalu mengirim data ke satu port saja. Broadcast dan beberapa frame dengan tujuan yang belum dikenal dapat diteruskan ke beberapa port dalam VLAN yang sama.

04 • Jenis Switch

Jenis-Jenis Switch

Unmanaged

Umumnya langsung digunakan tanpa konfigurasi khusus. Cocok untuk jaringan sederhana.

Managed

Dapat dikonfigurasi dan dipantau, misalnya untuk VLAN, keamanan port, dan trunk.

Layer 2

Meneruskan frame berdasarkan MAC address dan mendukung fungsi switching.

Layer 3

Selain switching, dapat melakukan routing antarjaringan atau antar-VLAN.

PoE Switch

Model tertentu dapat mengirimkan daya dan data melalui kabel Ethernet ke perangkat yang mendukung PoE.

Access Switch

Biasanya menjadi tempat komputer, printer, dan access point terhubung ke jaringan.

05 • VLAN dan Trunk

Switch dalam VLAN

VLAN memisahkan satu infrastruktur switch menjadi beberapa jaringan logis. Perangkat dalam VLAN yang berbeda umumnya memerlukan router atau Layer 3 switch untuk berkomunikasi.

Mode portKegunaan
AccessUmumnya membawa satu VLAN untuk perangkat akhir seperti PC atau printer.
TrunkMembawa lalu lintas beberapa VLAN melalui satu link menggunakan penandaan VLAN, biasanya IEEE 802.1Q.

Contoh konfigurasi Cisco IOS

enable configure terminal vlan 10 name SISWA vlan 20 name GURU interface range fa0/2-3 switchport mode access switchport access vlan 10 interface range fa0/4-5 switchport mode access switchport access vlan 20 interface fa0/1 switchport mode trunk end show vlan brief show interfaces trunk

Contoh ini mengasumsikan model switch mendukung perintah tersebut. Sintaks trunk dapat berbeda menurut model dan versi perangkat.

06 • Contoh Penggunaan

Contoh Switch di Laboratorium

PC 1 ──┐ PC 2 ──┤ PC 3 ──┼── Switch ─── Router/Internet Printer┤ Server ┘

Switch menghubungkan perangkat dalam LAN. Agar komputer dapat berkomunikasi, periksa kabel, status port, alamat IP, subnet mask, VLAN, dan aturan firewall.

Switch Layer 2 saja tidak otomatis melakukan routing antar-VLAN. Untuk komunikasi lintas subnet dibutuhkan perangkat Layer 3 dan konfigurasi routing yang benar.
07 • Kelebihan dan Batasan

Kelebihan dan Kekurangan

Kelebihan

Mudah menambah perangkat, mengurangi collision dibanding hub, dan meneruskan frame secara terarah.

Batasan

Switch biasa tidak otomatis menyediakan Wi-Fi, routing antar-VLAN, atau akses Internet tanpa perangkat dan konfigurasi tambahan.

08 • Kuis

Uji Pemahaman Switch

Pilih satu jawaban yang benar.

1. Switch Layer 2 meneruskan frame terutama berdasarkan ...

Switch Layer 2 menggunakan MAC address untuk meneruskan frame.

2. Fungsi VLAN adalah ...

VLAN memisahkan jaringan logis pada infrastruktur switch.

3. Port access umumnya digunakan untuk ...

Port access umumnya menghubungkan perangkat akhir pada satu VLAN.

4. Switch mempelajari MAC address sumber untuk ...

Switch membangun tabel MAC address dari frame yang diterimanya.

5. Perangkat yang dapat melakukan routing antar-VLAN adalah ...

Routing antar-VLAN membutuhkan fungsi Layer 3, seperti router atau multilayer switch.
09 • Ringkasan

Kesimpulan Switch

  • Switch menghubungkan perangkat dalam LAN.
  • Switch Layer 2 menggunakan MAC address.
  • Managed switch mendukung pengaturan seperti VLAN dan trunk.
  • Port access biasanya menghubungkan perangkat akhir ke satu VLAN.
  • Trunk membawa beberapa VLAN melalui satu link.
  • Routing antar-VLAN membutuhkan perangkat Layer 3.
