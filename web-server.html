Web Server

Pelajari cara kerja web server, HTTP/HTTPS, dan praktik membuat website menggunakan Apache pada Debian.

HTTP & HTTPSApacheDebian Linux
01 • PENGENALAN

Apa Itu Web Server?

Web server adalah perangkat lunak atau komputer yang menerima permintaan dari browser dan mengirimkan konten website melalui jaringan. Contoh perangkat lunaknya adalah Apache, Nginx, dan Microsoft IIS.

🌐 HTTPProtokol pertukaran data web.
🔒 HTTPSHTTP yang dilindungi TLS.
📁 Document RootFolder penyimpanan file website.
🖥️ BrowserKlien yang meminta halaman.
02 • FUNGSI

Fungsi Web Server

  • Menyajikan file HTML, CSS, JavaScript, gambar, dan file lainnya.
  • Menerima permintaan HTTP atau HTTPS.
  • Mengirim respons kepada browser.
  • Mencatat akses dan kesalahan pada log.
Contoh: Browser meminta halaman, lalu Apache mengirimkan file HTML kepada browser.
03 • CARA KERJA

Alur Kerja Web Server

1
Browser meminta halaman

Pengguna membuka alamat website.

2
Permintaan menuju server

Browser menghubungi IP dan port web server.

3
Server memproses permintaan

Server mencari file atau menjalankan aplikasi.

4
Respons dikirim

Browser menerima dan menampilkan halaman.

HTTP umumnya menggunakan port 80, sedangkan HTTPS menggunakan port 443.
04 • PRAKTIK DEBIAN

Instal Web Server Apache

1. Instal Apache

sudo apt update
sudo apt install apache2

2. Aktifkan layanan

sudo systemctl enable --now apache2
sudo systemctl status apache2

3. Buat halaman website

sudo nano /var/www/html/index.html

Isi file dengan HTML berikut:

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Website Sekolah</title>
</head>
<body>
  <h1>Selamat Datang</h1>
  <p>Apache berhasil berjalan.</p>
</body>
</html>

4. Uji server

curl http://localhost

Dari komputer klien, buka http://IP-SERVER dan ganti IP-SERVER dengan alamat Debian.

Pastikan klien dapat menjangkau server dan firewall mengizinkan port 80. HTTPS memerlukan konfigurasi TLS.
