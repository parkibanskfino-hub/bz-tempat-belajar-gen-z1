MATERI 01 • SISTEM OPERASI
💻

Pengenalan Sistem Operasi

Kenali pengertian sistem operasi, fungsi, jenis-jenis sistem operasi, komponen dasar, dan perannya dalam mengatur komputer.

🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan dapat:

  • Menjelaskan pengertian sistem operasi.
  • Mengetahui fungsi utama sistem operasi.
  • Mengenali jenis-jenis sistem operasi.
  • Mengetahui contoh sistem operasi.
  • Memahami peran sistem operasi dalam komputer.
01 — PENGENALAN

Apa Itu Sistem Operasi?

Sistem operasi atau Operating System (OS) adalah perangkat lunak utama yang mengatur dan mengelola sumber daya komputer serta menyediakan layanan agar aplikasi dapat berjalan.

Sistem operasi menjadi penghubung antara pengguna, aplikasi, dan perangkat keras. Tanpa sistem operasi, penggunaan komputer secara umum akan menjadi jauh lebih sulit.

⚙️

Pengelola Hardware

OS membantu mengatur penggunaan processor, memori, penyimpanan, dan perangkat lainnya.

🧩

Menjalankan Aplikasi

Sistem operasi menyediakan lingkungan agar berbagai aplikasi dapat digunakan.

👤

Penghubung Pengguna

OS menyediakan antarmuka agar pengguna dapat berinteraksi dengan komputer.

02 — FUNGSI

Fungsi Sistem Operasi

Sistem operasi memiliki banyak fungsi penting dalam menjalankan komputer.

🧠 Manajemen Proses

Mengatur proses yang sedang dijalankan oleh komputer dan membantu membagi penggunaan sumber daya processor.

💾 Manajemen Memori

Mengatur penggunaan memori agar program dapat berjalan dengan baik.

📁 Manajemen File

Mengatur file dan folder yang tersimpan pada perangkat penyimpanan.

🖥️ Antarmuka Pengguna

Menyediakan cara bagi pengguna untuk berinteraksi dengan komputer.

🔌 Manajemen Perangkat

Membantu sistem berkomunikasi dengan perangkat keras melalui driver dan mekanisme sistem operasi.

🔐 Keamanan

Menyediakan mekanisme untuk mengatur akun, hak akses, dan keamanan sistem.

03 — JENIS

Jenis-Jenis Sistem Operasi

Sistem operasi dapat digunakan pada berbagai jenis perangkat dan memiliki karakteristik yang berbeda.

🖥️

Desktop

Digunakan pada komputer desktop dan laptop. Contohnya Windows, Linux, dan macOS.

📱

Mobile

Dirancang untuk perangkat mobile seperti smartphone dan tablet. Contohnya Android dan iOS.

🖧

Server

Digunakan untuk menjalankan layanan dan mengelola sumber daya jaringan. Contohnya Windows Server dan berbagai distribusi Linux.

⚡

Embedded

Digunakan pada perangkat khusus seperti perangkat elektronik, mesin, dan sistem dengan fungsi tertentu.

05 — KOMPONEN DASAR

Bagian Penting dalam Sistem Operasi

Sistem operasi terdiri dari berbagai bagian yang bekerja bersama untuk mengelola komputer.

1

Kernel

Bagian inti sistem operasi yang menangani komunikasi antara software dan hardware serta pengelolaan sumber daya sistem.

2

User Interface

Bagian yang memungkinkan pengguna berinteraksi dengan sistem operasi, misalnya melalui GUI atau CLI.

3

File System

Mekanisme yang digunakan sistem operasi untuk mengatur dan menyimpan file serta folder.

4

Device Driver

Perangkat lunak yang membantu sistem operasi berkomunikasi dengan perangkat keras tertentu.

06 — CARA KERJA

Bagaimana Sistem Operasi Bekerja?

Secara sederhana, hubungan pengguna, aplikasi, sistem operasi, dan hardware dapat dipahami melalui alur berikut.

1

Pengguna Memberikan Perintah

Pengguna melakukan tindakan seperti membuka aplikasi, membuat file, atau menjalankan program.

2

Aplikasi Meminta Sumber Daya

Aplikasi membutuhkan sumber daya komputer untuk menjalankan tugasnya.

3

Sistem Operasi Mengatur

Sistem operasi mengatur akses aplikasi terhadap processor, memori, penyimpanan, dan perangkat lainnya.

4

Hardware Menjalankan Perintah

Perangkat keras menjalankan operasi sesuai instruksi yang telah dikelola oleh sistem.

💡

Contoh Sederhana

Ketika kamu membuka aplikasi browser, aplikasi tersebut membutuhkan RAM, processor, penyimpanan, jaringan, dan perangkat input/output. Sistem operasi membantu mengatur penggunaan sumber daya tersebut sehingga browser dapat berjalan.

RANGKUMAN

Yang Perlu Kamu Ingat

✓ Sistem operasi adalah perangkat lunak utama yang mengelola sistem komputer.
✓ OS menjadi penghubung antara pengguna, aplikasi, dan hardware.
✓ OS mengatur processor, memori, penyimpanan, dan perangkat.
✓ OS menyediakan antarmuka untuk pengguna.
✓ Contohnya Windows, Linux, macOS, Android, dan iOS.
✓ Kernel merupakan bagian inti dari sistem operasi.
