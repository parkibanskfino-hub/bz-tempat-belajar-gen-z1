Static Routing

Pelajari cara menambahkan rute secara manual, menentukan next hop, mengatur default route, dan menguji koneksi antarjaringan menggunakan Cisco CLI.

Manual RoutingNext HopCisco CLI
01 • Pengertian

Apa Itu Static Routing?

Static routing adalah metode routing dengan memasukkan jalur jaringan tujuan secara manual ke dalam tabel routing router oleh administrator.

Contoh: Router A ingin mengirim paket ke jaringan 192.168.3.0/24 melalui Router B yang memiliki alamat 10.0.0.2. Administrator menambahkan rute menuju jaringan tersebut melalui next hop 10.0.0.2.
Konfigurasi manual

Administrator menentukan jaringan tujuan dan jalur yang digunakan.

Jalur terkontrol

Rute tidak otomatis berubah mengikuti protokol routing dinamis.

Hemat sumber daya

Tidak memerlukan pertukaran pembaruan protokol routing dinamis.

Cocok untuk jaringan kecil

Berguna untuk topologi sederhana dan jalur tertentu.

02 • Topologi

Contoh Dua Router

LAN A Link antarrouter LAN B 192.168.1.0/24 192.168.2.0/24 | | Router A -------- 10.0.0.1 / 10.0.0.2 -------- Router B | | PC-A PC-B

Contoh alamat antarmuka pada link antarrouter adalah 10.0.0.1/30 untuk Router A dan 10.0.0.2/30 untuk Router B.

PerangkatInterface / jaringanAlamat
Router ALAN192.168.1.1/24
Router ALink ke B10.0.0.1/30
Router BLink ke A10.0.0.2/30
Router BLAN192.168.2.1/24
Alamat pada kedua ujung link harus berada dalam subnet yang sama. Interface harus aktif dan kedua router harus memiliki rute menuju jaringan LAN di seberang.
03 • Jenis

Bentuk Static Route

Network Static Route

Rute manual menuju jaringan tertentu, misalnya 192.168.2.0/24.

Default Static Route

Rute untuk tujuan yang tidak memiliki rute lebih spesifik, umumnya ditulis 0.0.0.0/0 untuk IPv4.

Host Route

Rute menuju satu alamat host tertentu, misalnya menggunakan prefix /32 pada IPv4.

Floating Static Route

Rute cadangan yang diberi administrative distance lebih tinggi daripada rute utama yang bersaing.

04 • Konfigurasi

Konfigurasi Static Routing Cisco

Contoh berikut mengasumsikan interface sudah dikonfigurasi dan link antarrouter aktif. Nama interface dapat berbeda pada perangkatmu.

Router A

enable configure terminal ip route 192.168.2.0 255.255.255.0 10.0.0.2 end show ip route

Router B

enable configure terminal ip route 192.168.1.0 255.255.255.0 10.0.0.1 end show ip route

Router A diarahkan ke LAN B melalui 10.0.0.2. Router B juga memerlukan rute balik ke LAN A melalui 10.0.0.1.

Penting: Rute harus tersedia pada kedua arah. Menambahkan rute di satu router saja belum tentu cukup untuk komunikasi dua arah.
05 • Default Route

Mengatur Jalur Default

Default route digunakan ketika tidak ada rute yang lebih spesifik untuk alamat tujuan. Pada router tepi, rute ini sering mengarah ke router upstream.

Router(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2

Perintah tersebut mengarahkan lalu lintas IPv4 yang tidak cocok dengan rute lebih spesifik ke next hop 10.0.0.2, dengan asumsi next hop dapat dijangkau.

Jangan memasang default route sembarangan. Pastikan next hop benar dan memang menjadi jalur menuju jaringan tujuan.
06 • Verifikasi

Menguji Static Routing

  1. Periksa interface.
    Gunakan show ip interface brief untuk melihat status interface router.
  2. Periksa tabel routing.
    Gunakan show ip route dan pastikan rute static muncul.
  3. Periksa IP host.
    Pastikan IP, subnet mask, dan default gateway setiap PC benar.
  4. Uji koneksi.
    Gunakan ping ke alamat IP tujuan dan periksa apakah ada balasan.
  5. Periksa jalur.
    Gunakan traceroute atau tracert jika perlu mengetahui jalur paket.
show ip route show ip interface brief ping 192.168.2.10 traceroute 192.168.2.10

Evaluasi Static Routing

09 • Kuis

Uji Pemahaman Static Routing

Pilih satu jawaban yang benar.

1. Static routing dikonfigurasi dengan cara ...

Administrator memasukkan rute secara manual.

2. Apa fungsi next hop?

Next hop adalah router selanjutnya dalam jalur menuju tujuan.

3. Perintah static route IPv4 di Cisco adalah ...

Perintah ip route digunakan untuk memasukkan rute IPv4.

4. Mengapa rute balik diperlukan?

Komunikasi dua arah memerlukan jalur pergi dan jalur kembali.

5. Apa fungsi default route IPv4?

Default route digunakan untuk tujuan yang tidak cocok dengan rute yang lebih spesifik.
10 • Ringkasan

Kesimpulan Static Routing

  • Static routing memasukkan rute secara manual.
  • Rute menentukan jaringan tujuan dan next hop atau interface keluar.
  • Default route digunakan jika tidak ada rute yang lebih spesifik.
  • Komunikasi antarjaringan membutuhkan rute pergi dan rute balik.
  • Gunakan show ip route dan ping untuk memeriksa koneksi.
