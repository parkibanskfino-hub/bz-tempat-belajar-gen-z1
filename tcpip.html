MATERI 04 • NETWORKING

TCP/IP

Pelajari model TCP/IP, fungsi setiap lapisan, protokol penting, serta cara data dikirim melalui jaringan komputer.

📚 4 Lapisan 🌐 Networking 🚀 Pemula 📝 5 Soal
01 — PENGERTIAN

Apa Itu TCP/IP?

TCP/IP adalah kumpulan protokol yang digunakan untuk menghubungkan perangkat dan memungkinkan pertukaran data melalui jaringan komputer, termasuk internet.

TCP/IP merupakan singkatan dari Transmission Control Protocol dan Internet Protocol. TCP membantu pengiriman data secara andal, sedangkan IP menangani pengalamatan dan penerusan paket menuju jaringan tujuan.

💡 Contoh: saat membuka situs web, perangkat menggunakan protokol jaringan seperti IP dan TCP atau protokol transport lain sesuai layanan yang digunakan.
02 — LAPISAN TCP/IP

Empat Lapisan TCP/IP

Model TCP/IP sering dijelaskan menggunakan empat lapisan. Setiap lapisan memiliki fungsi yang saling melengkapi.

4

Application Layer

Menyediakan protokol yang digunakan aplikasi untuk berkomunikasi melalui jaringan.

Contoh: HTTP, DNS, SMTP, DHCP.

3

Transport Layer

Mendukung komunikasi antaraplikasi menggunakan port dan mekanisme transport yang sesuai.

Contoh: TCP dan UDP.

2

Internet Layer

Menangani alamat IP dan penerusan paket antarjaringan.

Contoh: IPv4, IPv6, ICMP.

1

Network Access Layer

Menangani pengiriman data pada jaringan lokal melalui teknologi link dan media yang digunakan.

Contoh: Ethernet dan Wi-Fi.

03 — TCP DAN IP

Perbedaan TCP dan IP

TCP (Transmission Control Protocol)

TCP menyediakan komunikasi berorientasi koneksi dan mekanisme untuk pengiriman data yang andal, termasuk pengurutan data, pengiriman ulang, serta pengendalian aliran.

IP (Internet Protocol)

IP menyediakan pengalamatan logis dan membantu paket mencapai jaringan tujuan. IP tidak menjamin bahwa setiap paket pasti sampai atau tiba sesuai urutan.

📌 Ingat: TCP membantu keandalan pengiriman data, sedangkan IP menangani pengalamatan dan penerusan paket.
04 — PROTOKOL PENTING

Contoh Protokol TCP/IP

HTTP dan HTTPS

Digunakan untuk pertukaran data web. HTTPS melindungi komunikasi menggunakan TLS.

DNS

Membantu menerjemahkan nama domain, seperti example.com, menjadi informasi alamat IP yang diperlukan.

DHCP

Membantu perangkat mendapatkan konfigurasi jaringan secara otomatis, misalnya alamat IP, subnet mask, dan gateway.

ICMP

Digunakan untuk pesan kontrol dan diagnostik jaringan. Perintah ping umumnya memanfaatkan ICMP Echo pada jaringan IP.

Ethernet dan Wi-Fi

Menyediakan teknologi koneksi jaringan lokal yang membawa data melalui media kabel atau nirkabel.

05 — PROSES KOMUNIKASI

Bagaimana Data Berjalan?

Saat aplikasi mengirim data, data diproses oleh lapisan protokol yang sesuai. Lapisan transport dapat membaginya menjadi bagian data, IP membawa paket menuju tujuan, dan lapisan akses jaringan mengirimkannya melalui link yang tersedia.

  • Aplikasi menghasilkan data yang akan dikirim.
  • Transport menangani komunikasi antaraplikasi.
  • Internet Layer membantu paket mencapai jaringan tujuan.
  • Network Access mengirim data melalui jaringan lokal.
  • Perangkat penerima memproses data agar dapat digunakan aplikasi.
💡 TCP/IP menggunakan proses enkapsulasi: setiap lapisan menambahkan informasi yang diperlukan untuk menjalankan fungsi komunikasinya.
